# 猛人快传

这是一个面向 Android 与 Windows 的传输工具。v1.7.2 在保留局域网优先的基础上，可通过用户自己的 VPS 端到端加密发送远程文字、链接和单个不超过 200 MiB 的任意文件，并针对高延迟线路扩大有限流水窗口、容忍迟到回执。

安装、远程配置和常见问题见 [v1.7.2 安装与测试说明](docs/猛人快传-v1.7.2-安装与测试说明.md)，版本更新摘要见 [v1.7.2 发布说明](docs/猛人快传-v1.7.2-发布说明.md)。

## 第一阶段范围

- Android 与 Windows 客户端
- 每台设备拥有稳定身份和可修改的显示名称
- 自动发现同一局域网内运行本软件的设备
- 向一个或多个设备发送文本、链接、图片、视频和任意文件
- 接收方确认或拒绝陌生设备的传输
- 大文件分块传输、完整性校验和同一局域网内断点续传
- 网络接口或 IP 地址变化后自动重新发现，不要求重新配置设备

## 暂不包含

- S3、公共云账号系统
- 离线远程消息、可靠后台推送、远程大文件和公网点对点加速
- 剪贴板监听或同步
- iOS、macOS、HarmonyOS 和 Web 客户端

## 重要边界

“换网络后仍可用”表示移动设备进入新的局域网后，可以自动发现该局域网中的设备。例如手机和笔记本从公司带回家后，可以发现家中的 Windows 电脑。

纯局域网模式无法从家中连接仍留在公司的电脑。如果公司网络启用了终端隔离、VLAN 隔离或禁止设备间通信，任何不经过公网服务器/VPN 的局域网软件都会受到限制。v1.7.0 可选择用户自有 VPS，但界面会明确显示“公网 VPS 中转”，并且同一设备存在本地路线时仍优先直连。

## 实现方向

客户端使用 Flutter 共用 Android 与 Windows 代码。局域网发现采用 UDP 广播，第一条文件传输链路采用 HTTP 流式传输。详细设计见 [架构说明](docs/architecture.md)。

## 当前进度

已经实现：

- Android/Windows 双平台 Flutter 工程。
- 永久设备 ID、默认名称和自定义改名。
- UDP 广播附近设备，按永久 ID 合并 IP 变化后的同一设备。
- 设备离线超时和手动刷新。
- 系统文件选择器，可连续选择多个文件发送。
- 接收方逐文件确认或拒绝。
- 点击设备进入聊天窗口，发送文字、可点击链接和任意附件。
- 文件发送显示实时百分比、进度条和已发送/总大小。
- 等待确认和传输过程中均可由发送端停止，并清理接收端未完成文件。
- 发送端和接收端都显示实时传输速度与进度。
- Windows 支持 Enter 发送、Shift+Enter 换行和拖放文件发送。
- 收到的文件可从聊天气泡直接调用系统应用打开，并显示实际保存路径。
- Android 接收文件自动导出到系统下载或用户选择的 SAF 文件夹，成功后删除应用缓存副本。
- Android 注册系统分享入口，可从相册和文件管理器把单个或多个文件分享到猛人快传。
- Android 同时支持微信“其他应用打开”（ACTION_VIEW），可把表格等文件加入待发送列表。
- 大文件接收采用写盘背压和后台系统目录导出，避免持续占用 Flutter UI 事件循环。
- 会话可清空消息/缓存或移除设备，已保存文件不受缓存清理影响。
- 可选择主题颜色、默认保存位置和 Windows 开机自启动。
- 支持完整浅色、深色、跟随系统模式，并可单独选择强调色。
- Android 诊断日志可导出/清除，按 1 MB 轮换并清理 7 天前的记录。
- Windows 关闭按钮隐藏到系统托盘，单击托盘图标恢复，右键菜单可彻底退出。
- Windows 单实例运行；再次点击快捷方式会恢复原窗口，不会重复占用接收端口。
- 二级路由环境优先使用已建立的双向二维码配对通道。
- 重复扫码/自动重连使用双方一致的连接选择规则，防止交叉连接互相关闭；发送时可回退到实时局域网直连。
- 本机保存最近 1000 条文字和文件消息记录。
- 接收文件名安全清理、重名避让和临时文件原子落盘。
- 本机回环端到端文件流测试。
- 在线 VPS 密文中转、系统安全存储、远程文字/链接/单文件 200 MiB 以内任意文件、路线标识和公网停止清理。

尚未实现：离线密文队列、可靠后台通知、超过 200 MiB 的远程大文件、分块断点续传、公网点对点加速、设备公钥认证、信任设备免确认、多目标同时发送和正式安装向导。

## 开发环境

项目内已放置 Flutter SDK（`.tools/flutter`，不会提交到 Git）。由于当前项目绝对路径含中文，而 Flutter 3.47 的部分 Windows 工具对中文路径兼容不完整，使用包装脚本可临时映射纯英文盘符：

```powershell
.\scripts\flutter.ps1 analyze
.\scripts\flutter.ps1 test
```

生成 Windows 安装包前还需安装 Visual Studio 的“使用 C++ 的桌面开发”组件，并启用 Windows 开发人员模式。生成 Android APK 前还需安装 Android SDK、platform-tools 和对应构建工具。

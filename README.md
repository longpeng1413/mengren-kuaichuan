# 猛人快传

这是一个面向 Android 与 Windows 的传输工具：局域网优先高速直传，像聊天一样互发文字、图片、视频、语音和任意文件；也可以选择接入用户自建 VPS，进行端到端加密的公网传输。

当前正式版为 **v1.11.2+38**（手机和电脑）：语音录完自动调整到正常音量，解决播放声音太小，见 [v1.11.2 发布说明](docs/猛人快传-v1.11.2-发布说明.md)。v1.11.1（仅电脑端）修复电脑端无法录语音，见 [v1.11.1 发布说明](docs/猛人快传-v1.11.1-发布说明.md)。v1.11.0 新增语音消息、离线语音转文字和语音输入，见 [v1.11.0 发布说明](docs/猛人快传-v1.11.0-发布说明.md) 和 [安装与测试说明](docs/猛人快传-v1.11.0-安装与测试说明.md)。最近几个版本：

## 下载与安装

到 [Releases](https://github.com/longpeng1413/mengren-kuaichuan/releases/latest) 下载最新正式版：

- **Android**：`mengren-kuaichuan-android-vX.Y.Z.apk`，直接安装；以后在“设置 → 软件更新”一键升级。只修电脑端问题的版本（如 v1.11.1）不带 APK，请用最近一个带 APK 的版本。
- **Windows**：`mengren-kuaichuan-windows-x64-vX.Y.Z.zip`（便携版，不需要安装）。解压到一个固定文件夹，双击包里的“创建桌面快捷方式.cmd”，再运行一次 `enable_lan_access.cmd` 放行局域网端口（UDP 53317、TCP 53318）。以后同样在软件里一键升级。

程序没有数字签名，Windows 或安全软件可能提示“未知发布者”，选择“仍要运行”即可。名为 `asr-model-…` 的预发布页存放的是语音识别模型，软件第一次转文字时会自动下载，不需要手动下载。

## 功能

**设备与连接**

- Android 与 Windows 客户端，每台设备有固定的设备 ID 和可修改的名称。
- 自动发现同一局域网（含手机热点）内运行本软件的设备；换网络后自动重新发现，不需要重新配置。
- 自动发现失败时（例如二级路由），可扫描二维码或手动输入 IP 和配对码建立“局域网安全连接”，之后自动重连。
- 可选接入自建 VPS：不在同一网络的设备经端到端加密中转互传，界面明确显示实际路线（局域网直连 / 局域网安全连接 / 公网 VPS 中转），能直连时优先直连。

**聊天与传输**

- 点开设备即进入对话：发送文字、链接、图片、视频、压缩包等任意文件；电脑上可把文件直接拖进对话框。
- 语音消息：按住麦克风说话、松开发送、上滑取消，最长 60 秒。
- 语音转文字与语音输入：长按语音“转文字”，或点一下麦克风把说的话变成文字。识别在本机离线完成，模型（约 229 MB）首次使用时下载。
- 长按（电脑上右键）消息：复制、转发到其他设备、引用回复、删除；点击引用可跳回原消息。
- 输入框粘贴截图、图片和文件（电脑 Ctrl+V，手机长按输入框）。
- 图片显示为小缩略图；聊天记录按天显示日期；本机保存最近 1000 条消息。
- 发送和接收都显示进度与速度，可随时停止，并清理未完成的文件。
- 对方不在线时，文字和文件先排队，对方上线后自动发出（最多 100 条，保留 7 天）。
- 收文件可设为自动接收（所有设备 / 只限连接过的设备 / 每次询问）。
- Android 可从相册、文件管理器、微信“用其他应用打开”分享文件到猛人快传；收到的文件保存到系统下载或自选文件夹。

**系统与维护**

- 软件内检查更新与一键自动更新（只认 GitHub 正式版，下载后核对 SHA-256）。
- Windows：关闭按钮隐藏到托盘、单实例、开机自启动（可静默启动只在托盘运行）、记住窗口大小。
- Android：可选后台持续接收（前台服务与常驻通知），华为等手机提供“系统后台设置”入口。
- 浅色 / 深色 / 跟随系统主题和强调色。
- 诊断日志可导出、清除（1 MB 轮换、保留 7 天）。
- 每种缓存都会自动清理，并能在设置里看到占用、一键清空：更新缓存（每次启动清空）、发送缓存（30 天 / 1 GB）、语音消息（30 天 / 500 MB）、语音识别模型（可删除）。

## 暂不包含

- S3、公共云账号系统、公共中转服务器
- 超过 200 MiB 的公网单个文件、公网点对点加速
- 传输中断后的断点续传（中断后需要重新发送）
- 一次同时发给多台设备（可以逐台发送或转发）
- 剪贴板监听或同步
- iOS、macOS、HarmonyOS 和 Web 客户端

## 重要边界

“换网络后仍可用”表示移动设备进入新的局域网后，可以自动发现该局域网中的设备。例如手机和笔记本从公司带回家后，可以发现家中的 Windows 电脑。

纯局域网模式无法从家中连接仍留在公司的电脑。如果公司网络启用了终端隔离、VLAN 隔离或禁止设备间通信，任何不经过公网服务器/VPN 的局域网软件都会受到限制。这类情况可以使用自己的 VPS 中转，界面会明确显示“公网 VPS 中转”，并且同一设备存在本地路线时仍优先直连。

“离线排队”只在发送方这台设备上排队，不经过任何服务器：发送方要保持运行，对方上线后才会发出。Android 手机切到后台后可能被系统冻结（华为、荣耀等尤其明显），需要打开“后台持续接收”并在系统里允许猛人快传后台运行。

电脑上的 AdGuard、杀毒软件或防火墙如果接管了猛人快传的网络连接，可能导致大文件发送中途断开；请在这些软件里把猛人快传设为不过滤。

## 实现方向

客户端使用 Flutter 共用 Android 与 Windows 代码。局域网发现采用 UDP 广播，文件和消息通过局域网 HTTP 流式传输；二维码配对使用 WebSocket 通道；公网中转为自建的 WebSocket 服务，内容在客户端用家庭口令加密。语音识别使用 sherpa-onnx 和 SenseVoice 离线模型。详细设计见 [架构说明](docs/architecture.md)。

## 开发环境

开发工具统一安装在 `D:\yinyong\MengrenDev`，仓库中的 `.tools` 是指向该目录的本地连接，不会提交到 Git。使用包装脚本可自动配置 Flutter、JDK、Android SDK、Pub 和 Gradle 路径：

```powershell
.\scripts\flutter.ps1 analyze
.\scripts\flutter.ps1 test
.\scripts\flutter.ps1 build apk --release
.\scripts\flutter.ps1 build windows --release
.\scripts\package_windows.ps1 -SkipBuild
```

Windows 打包脚本会把防火墙配置脚本、VC++ 运行库和使用说明一起放入 ZIP，避免只压缩 Flutter 的原始 Release 目录。生成 Windows 包需要 Visual Studio 的“使用 C++ 的桌面开发”组件（含 C++ ATL）并启用 Windows 开发人员模式；生成 Android APK 需要 Android SDK、platform-tools 和对应构建工具。语音识别模型不在仓库里，由软件运行时从 Releases 下载。

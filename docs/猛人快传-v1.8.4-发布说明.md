# 猛人快传 v1.8.4

修复手机端一键更新下载不动。

- **手机端走系统代理下载**：以前手机上的猛人快传不读系统代理设置，即使手机开着代理，也是直连 GitHub 下载，在国内经常连不上或极慢，等一会儿就提示失败。现在会和浏览器一样使用手机的系统代理（Wi-Fi 代理或代理软件的“系统代理”）。电脑端原来就会读系统代理。
- **下载进度显示速度**：例如“已下载 12.3 MB / 69.2 MB · 3.5 MB/s”，一眼能看出是否在下载。
- **失败提示更具体**：连不上 GitHub 时会提示确认代理已开启，并可“去网页手动下载”或用电脑把安装包发到手机。
- 诊断日志会记录下载时用的代理（`update_network proxy=…`），方便排查。

**注意：手机上的 v1.8.3 及更早版本没有这个修复，这一次需要手动安装 v1.8.4**（浏览器下载，或用电脑上的猛人快传把安装包发到手机）。装好后以后的版本就能一键更新。电脑端照常一键更新即可。

## 下载

- Android：`mengren-kuaichuan-android-v1.8.4.apk`，直接覆盖安装（签名与之前版本相同）。
- Windows：`mengren-kuaichuan-windows-x64-v1.8.4.zip`；已装 v1.8.0 以上的在「设置 → 软件更新」一键升级。

校验值见 `SHA256SUMS-v1.8.4.txt`。程序没有数字签名，Windows 或安全软件可能会提示，选择「仍要运行」即可。

# 猛人快传 v1.7.5 安装与使用说明

## Android

1. 直接打开 `mengren-transfer-android-v1.7.5.apk` 覆盖安装，不要先卸载。
2. 确认首页标题为“猛人快传 v1.7.5”。原设备身份、设置、聊天记录和公网配置应仍保留。
3. 若应用刚从后台恢复或刚切换网络，请等待 3–5 秒让局域网发现和公网连接自动恢复。

## Windows

1. 从系统托盘右键彻底退出旧版。
2. 完整解压 `mengren-transfer-windows-x64-v1.7.5.zip` 到固定文件夹，不要只复制 EXE；升级时覆盖同一文件夹即可。
3. 在新目录运行一次 `enable_lan_access.cmd`，并在 Windows 用户账户控制中选择“是”。脚本会把防火墙规则绑定到当前程序路径，并覆盖公用、专用和域网络中的私有局域网地址；以后更换 Wi-Fi 无需重配。
4. 如果以后移动了解压目录，需要在新目录重新运行一次 `enable_lan_access.cmd`。
5. 启动 `lan_transfer.exe`，确认标题为“猛人快传 v1.7.5”。

## 后台恢复说明

- Android 在后台期间不保证接收新消息或发现新设备；离线消息和可靠后台通知尚未实现。
- 返回应用后，局域网发现、已保存的局域网安全连接和公网 VPS 会自动恢复。若网络刚切换，等待数秒属于正常现象。
- 如果仍出现卡死，请在卡住前后从设置导出诊断日志发送；不需要先清除数据或卸载。

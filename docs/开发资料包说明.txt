猛人快传 完整开发资料包说明（适用于 v1.11.0 及以后）

包含：
1. app：Android/Windows Flutter 完整源代码、依赖锁定文件和 125 项应用测试。
2. packages/remote_protocol、relay_server：公网中转的加密协议和自建中转服务。
3. docs：架构、安装测试和各版本开发交接说明（先读 AI_HANDOFF.md 和 AGENTS.md）。
4. scripts：中文路径环境下的 Flutter 构建包装脚本、Windows 打包脚本。
5. packaging：Windows 防火墙脚本和创建桌面快捷方式脚本。
6. private-signing/debug.keystore：当前 Android APK 更新签名密钥（不在 Git 仓库里）。

不包含：
- .tools 本地 SDK（Flutter、JDK、Android SDK 等，约 11 GB，可重新下载或从原电脑另行复制）。
- app/build 编译产物（可重新构建）。
- app/.dart_tool、Gradle、Pub 等缓存。
- 语音识别模型（约 229 MB，在 GitHub 预发布 asr-model-sensevoice-2024-07-17，软件运行时自动下载）。

编译 Windows 版需要 Visual Studio 生成工具（含“使用 C++ 的桌面开发”和 C++ ATL），
并在系统设置里打开“开发人员模式”。

private-signing 目录不得公开分享；完整开发资料包建议仅保存在自己的私密网盘。

# 猛人快传 v1.8.1

**界面升级**：窗口更小巧、主界面和设置页重新设计，用起来更清爽直观。传输功能、聊天记录和已配对设备都不变。

- 窗口默认约 500×760，在屏幕正中打开，不再一打开就占半个屏幕。
- 主界面：上方本机卡片显示名称、在线状态和设备 ID；下方「附近设备」列表用小圆点标出路线（绿色局域网直连、蓝色安全连接、黄色公网中转）。
- 设置页按外观、常规、软件更新、远程传输、设备管理、诊断分组；长说明收进「使用帮助」，点开才显示。
- 新增和图标一致的「宝石红」强调色；聊天气泡、输入框和按钮统一为圆角风格，深色模式同步优化。
- Windows 改用微软雅黑字体，中文更清晰。
- 程序文件夹里新增「创建桌面快捷方式.cmd」，双击即可在桌面创建快捷方式。

## 下载

已安装 v1.8.0 的，在「设置 → 软件更新」点「检查更新」即可一键升级。

- Android：`mengren-kuaichuan-android-v1.8.1.apk`，直接覆盖安装（签名与之前版本相同）。
- Windows：`mengren-kuaichuan-windows-x64-v1.8.1.zip`，解压后双击「创建桌面快捷方式.cmd」，再从桌面图标打开。

从 v1.8.1 起，安装包改用和仓库名一致的拼音名（GitHub 不支持中文文件名）。

校验值见 `SHA256SUMS-v1.8.1.txt`。程序没有数字签名，Windows 或安全软件可能会提示，选择「仍要运行」即可。

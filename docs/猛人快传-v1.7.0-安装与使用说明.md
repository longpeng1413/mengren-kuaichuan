# 猛人快传 v1.7.0 安装与使用说明

v1.7.0 是正式发布版。公网中转服务器、DNS、TLS、WSS、接收回执和任意文件生命周期均已验证。

## 一、安装前准备

- 支持 Android 和 Windows，不支持 iOS、macOS 或独立鸿蒙客户端。
- 参与传输的设备应全部安装 v1.7.0，不要与旧测试版或不同协议版本混合使用。
- Android 必须覆盖安装旧版本，不要先卸载；卸载会清除应用设置和本地聊天记录。
- 公网远程首版要求发送方和接收方同时在线，并保持猛人快传正在运行。

正式发布文件：

- Android：`猛人快传-android-v1.7.0.apk`
- Windows：`猛人快传-windows-x64-v1.7.0.zip`

## 二、Android 安装

1. 把 `app-release.apk` 发送或复制到手机。
2. 在手机文件管理器中点击 APK。
3. 如果系统阻止安装，按提示临时允许该文件管理器“安装未知应用”。
4. 选择“更新”或“覆盖安装”，不要卸载旧版。
5. 安装完成后打开软件，标题应显示“猛人快传 v1.7.0”。

如果系统提示签名不一致，应立即停止，不要删除旧版；正式 APK 已确认继续使用原升级证书。

## 三、Windows 安装与启动

1. 先在右下角系统托盘找到猛人快传图标，右键选择“彻底退出”，结束正在运行的 v1.6.1。
2. Windows 版本不是单独一个 EXE。必须保留 Release 目录中的 `data` 文件夹和全部 DLL，不能只复制 `lan_transfer.exe`。
3. 双击 `lan_transfer.exe`，窗口标题应显示“猛人快传 v1.7.0”。
4. Windows 首次弹出防火墙提示时，允许“专用网络”访问；局域网发现使用 UDP 53317，传输使用 TCP 53318。
5. 点击窗口右上角关闭按钮只会隐藏到托盘；必须在托盘菜单中选择“彻底退出”才会结束程序。

如果点击 v1.7.0 后仍显示 v1.6.1，说明旧版仍在托盘运行，应先彻底退出旧版再启动。

## 四、配置公网远程传输

所有需要跨地区通信的手机和电脑都要分别配置，而且三项内容必须一致。

1. 打开“设置”。
2. 找到“公网远程传输”，点击“配置公网远程传输”。
3. 开启“启用 VPS 远程连接”。
4. “中转地址”填写：

   `wss://relay.meng1314.de5.net/v1/relay`

5. “VPS 访问令牌”填写管理员提供的 64 位令牌。不要填写 VPS 登录密码，也不要在令牌前后增加空格。
6. “家庭加密口令”自行设置为 12–256 位；建议使用至少 16 位的字母、数字和中文组合。
7. 每台设备必须填写完全相同的家庭加密口令，然后点击保存。

访问令牌用于限制陌生设备连接 VPS；家庭加密口令用于端到端加密正文和文件。家庭口令不会发送给 VPS，两者都会保存在系统安全存储中。

## 五、验证公网连接

1. 两台设备都打开猛人快传并保持前台运行。
2. 让设备使用不同网络，例如一台连接家庭 Wi-Fi，另一台关闭 Wi-Fi 使用移动数据。
3. 等待对方出现在设备列表中。
4. 公网设备会显示云图标和“公网 VPS 中转”。
5. 先双向发送一条短文字，再测试链接和小图片。
6. 最后测试 APK、视频和接近但不超过 200 MiB 的文件，以及发送过程中点击停止。

如果两台设备处于同一个 Wi-Fi 或手机热点，软件会优先使用“二维码本地连接”或“局域网直连”，不会为了测试而绕行 VPS。这是正常行为。

## 六、v1.7.0 公网功能范围
公网 VPS 中转目前支持：

- 在线文字；
- HTTP/HTTPS 链接；
- 单个不超过 200 MiB 的图片、视频、APK、压缩包、文档和其他文件；
- 公网文件发送进度和发送端手动停止；
- 取消后清理接收端未完成的 `.part` 文件。

公网暂不支持：

- 离线消息；
- 可靠后台通知或系统推送；
- 单个超过 200 MiB 的文件；
- 断点续传；
- 公网点对点加速。

超过 200 MiB 的文件仍应使用局域网或手机热点发送。

## 七、局域网和手机热点使用

1. 两台设备连接同一个 Wi-Fi，通常会自动发现对方。
2. 一台手机也可以打开便携热点，另一台手机连接该热点；不需要公司或家庭路由器。
3. 自动发现失败时，在任意设备打开“二维码 / 手动连接”，让另一台设备扫码。
4. 仍无法连接时，可手动填写二维码页面显示的 IP 和配对码。
5. 所有参与设备应使用同一版本。

发送视频或大文件时，手机热点应优先选择 5 GHz，并关闭“兼容模式/最大兼容性”。两台设备尽量靠近并关闭省电模式。用户实测 2.4 GHz 约为 8 MiB/s，切换 5 GHz 后可达到约 60–70 MB/s，实际速度取决于设备和环境。

## 八、常见问题

### 公网设备没有出现

- 确认双方都已启用 VPS 远程连接。
- 中转地址必须以 `wss://` 开头，并包含 `/v1/relay`，不能填写健康检查地址。
- 确认访问令牌完全一致、没有空格或换行。
- 双方软件必须正在运行；首版没有离线消息和可靠后台唤醒。
- 检查手机是否限制了后台网络、电池或移动数据。

### 设备出现但消息解密失败

双方的家庭加密口令不一致。重新填写完全相同的口令并保存。

### 显示局域网直连而不是公网 VPS 中转

双方当前可以直接通信，软件按设计优先走局域网。测试公网时让两台设备切换到不同网络。

### Windows 打开的还是旧版本

旧版仍在托盘运行。右键托盘图标选择“彻底退出”，再启动 v1.7.0 目录中的 `lan_transfer.exe`。

### 大文件速度慢

先确认当前路线。公网经美国 VPS 中转，速度受双方上行、跨境延迟和 VPS 带宽影响；局域网热点应使用 5 GHz。2.4 GHz 约 8 MiB/s 通常是无线频段限制，不是软件限速。

## 九、安全提醒

- 不要公开 VPS 访问令牌、家庭加密口令、VPS 密码或 SSH 私钥。
- 不要把这些秘密写入 Git、安装说明、截图或诊断日志。
- 如果访问令牌曾在聊天或截图中明文出现，应在测试完成后更换。
- 设置页会明确显示当前使用的是局域网还是公网；公网发送文件时可以随时停止。

## 十、建议测试顺序

1. Android 与 Windows 分别确认标题为 v1.7.0。
2. 同一局域网双向发送文字和小图片。
3. 手机热点下双向发送文字和大文件，并确认使用 5 GHz。
4. 不同网络下确认显示“公网 VPS 中转”。
5. 公网双向测试文字、链接、图片、APK、视频和接近 200 MiB 的文件。
6. 公网文件发送中点击停止，确认双方恢复正常且没有残留未完成文件。
7. 测试错误家庭口令、断网和对方离线时的提示。

如遇到界面长时间无响应，请记录发生前的操作和传输方向；重启后从“设置 → 诊断日志”导出日志，以便继续定位。

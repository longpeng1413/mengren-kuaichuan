# 猛人快传 v1.8.1 安装与测试说明

v1.8.1 是界面升级版：窗口变小、主界面和设置页重新设计，并新增「创建桌面快捷方式.cmd」。传输功能、协议、设置、聊天记录和已配对设备都不变。

## 安装

### 已经装了 v1.8.0

不用手动下载。打开「设置 → 软件更新 → 检查更新」，点「立即更新」即可；或者等软件每天自动检查时弹出提示。

### 第一次安装，或者还在用 v1.7.x（Windows）

1. 在右下角托盘的猛人快传图标上右键「彻底退出」旧版。
2. 把压缩包完整解压到一个固定文件夹（不要放在 `C:\Program Files` 里，否则无法一键更新）。
3. 双击文件夹里的「创建桌面快捷方式.cmd」，桌面会出现「猛人快传」图标；原来的快捷方式会被替换成指向新文件夹。
4. 如果手机发现不了电脑，双击 `enable_lan_access.cmd`，在弹窗里点「是」。
5. 检查：窗口标题为「猛人快传 v1.8.1」。

### Android

直接覆盖安装 APK（签名与之前相同）。已装 v1.8.0 的也可以在软件里一键更新。

## 这一版的变化

- **窗口**：默认约 500×760，在屏幕正中打开（以前是 1280×720、贴在左上角）；可以拉大，最小 380×520。小屏幕会自动缩小。
- **主界面**：上方是本机卡片（名称、在线状态、设备 ID、VPS 状态），下方是「附近设备」列表。每台设备前面的小圆点表示路线：绿色 = 局域网直连，蓝色 = 局域网安全连接，黄色 = 公网 VPS 中转。没找到设备时有清楚的提示和「二维码 / 手动连接」按钮。
- **设置页**：按「外观 / 常规 / 软件更新 / 公网远程传输 / 设备管理 / 诊断 / 使用帮助」分组，每组一张卡片；长说明收进「使用帮助」，点开才显示。强调色改成一排色点，新增和图标一致的「宝石红」（没选过颜色的会默认用它，已经选过的保持不变）。
- **聊天页**：顶部显示对方设备图标；自己发的是浅红气泡，对方发的是白色气泡；输入框改为圆角。
- **Windows 字体**：改用微软雅黑，中文更清晰。
- **GitHub 安装包改名**：从 v1.8.1 起叫 `mengren-kuaichuan-android-v1.8.1.apk` 和 `mengren-kuaichuan-windows-x64-v1.8.1.zip`（和仓库名一致）。v1.8.0 的自动更新照样能找到。

## 测试一键更新（用另一台装了 v1.8.0 的电脑）

1. 在那台电脑上打开 v1.8.0，进入「设置 → 软件更新 → 检查更新」，应提示发现 v1.8.1。
2. 点「立即更新」：下载 → 校验 → 程序关闭 → 几秒后自动重新打开，并提示「已更新到 v1.8.1」。
3. 重新打开后应该是新界面：窗口变小、居中，标题为 v1.8.1。
4. 聊天记录、已配对设备、保存位置等设置都应保留。

遇到问题时，请在「设置 → 诊断」导出诊断日志发给开发者，日志里以 `update_` 开头的记录就是更新过程。

# 猛人快传 v1.10.0

- **长按消息像微信一样操作**：手机长按、电脑右键任意一条消息，可以复制、转发、引用、删除。转发可以发给局域网里任何一台设备（对方不在线就排队，上线后自动送达），转发文件会切到对方的对话里显示进度、可以随时停止。引用回复会在气泡下方显示灰色的引用内容。删除只删除本机的聊天记录，已保存的文件不受影响。电脑上还能把收到的图片/文件“复制”后直接粘贴到微信、画图或文件夹里，或“在文件夹中显示”。
- **输入框可以粘贴图片和文件**：电脑上截图或在资源管理器里复制文件后，在输入框按 Ctrl+V（或右键）即可发送；手机长按输入框，剪贴板里有图片或文件时会出现“粘贴图片/粘贴文件”，输入法剪贴板里的图片也能直接发。发送前会先预览确认。粘贴的截图保存在“发送缓存”里，30 天或超过 1 GB 时自动清理，设置里可一键清空。
- **图片只显示小缩略图**：聊天里的图片不再显示文件名、大小和保存位置，只显示一张小图，点开用系统看图；手机收到的图片也能显示缩略图了。其他文件改成紧凑的文件卡片。
- **电脑静默启动**：打开“开机自启动”后，默认开机只在任务栏托盘里运行、不弹出窗口，照常接收文件和消息；可在设置里关闭“静默启动”。
- 输入框的长按/右键菜单改为中文（剪切、复制、粘贴、全选）。

## 下载

已安装 v1.8.0 及以上的，在「设置 → 软件更新」点「检查更新」即可一键升级。

- Android：`mengren-kuaichuan-android-v1.10.0.apk`，直接覆盖安装（签名与之前版本相同）。
- Windows：`mengren-kuaichuan-windows-x64-v1.10.0.zip`。

校验值见 `SHA256SUMS-v1.10.0.txt`。程序没有数字签名，Windows 或安全软件可能会提示，选择「仍要运行」即可。

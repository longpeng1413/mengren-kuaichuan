# 猛人快传 v1.7.7 修复候选版 rc.2

应用版本 `1.7.7+25`，标签 `v1.7.7-rc.2`。用户已确认本轮交互修复可用并授权同步 GitHub，并明确确认上次 Windows 后台卡死修复已连续使用几天正常。仍保留候选版标记，不替换 v1.7.6 正式版；休眠/网络恢复及 Android 稳定性全面回归尚待明确确认。

## 本轮修复

- 文字和链接统一支持选取：Windows 按住鼠标拖动选择，右键复制选中内容或复制全部；Android 长按选择并调整范围复制。单击 HTTP/HTTPS 链接仍打开浏览器，拖选或长按不会打开。
- Windows 包中的启动程序改为 `猛人快传.exe`，解压目录/ZIP 使用中文品牌名；防火墙脚本兼容新旧名称。
- 保留设置、聊天和安全存储的数据身份，不清理用户数据；Android 升级签名保持不变。
- 继承 rc.1 的 Windows UDP 防空转修复，保留托盘后台新设备发现及已有设备单播保活。配对协议 2、公网协议 3、VPS 和 200 MiB 上限不变。

## 验证

- 静态检查通过，应用 58 项测试通过，含 8 项选择/复制测试、聊天气泡集成、中文打包和原有 11 项 UDP 回归。
- Android / Windows Release 构建通过，APK Manifest 为 1.7.7+25，v2 升级证书不变；Windows ZIP 28 个条目全部可读。
- 用户运行的中文名称 Windows 新版单实例验证通过，UDP 53317 / TCP 53318 由同一进程监听。
- Windows 连续几天后台实际使用未再卡死已由用户确认；休眠唤醒、切换网络及 Android 稳定性尚未完成全面明确验收。

## 安装

Windows 完整解压 ZIP 到固定目录，先彻底退出旧版，运行一次包内 `enable_lan_access.cmd`，再打开 `猛人快传.exe`。不要单独移动 EXE。原开机自启动指向旧目录时，在新版设置中关闭后重新开启。

Android APK 可覆盖安装 rc.1 或 v1.7.6，不要先卸载。中转地址、令牌和家庭加密口令不需要更换。

附件沿用用户已测试的原包，保持校验值不变；包内说明是打包当时的本地测试说明，最新发布/验收状态以本页及仓库交接说明为准。

GitHub 对中文附件文件名会截断，下载附件使用兼容的英文文件名并显示中文说明；仅外层下载名不同，Windows 解压后的启动程序仍为 `猛人快传.exe`，与本地中文包内容相同。

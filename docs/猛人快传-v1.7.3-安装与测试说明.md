# 猛人快传 v1.7.3 安装与测试说明

## Android

1. 直接打开 `猛人快传-android-v1.7.3.apk` 覆盖安装，不要先卸载。
2. 确认标题显示“猛人快传 v1.7.3”，原来的VPS设置、设备身份和聊天记录仍在。
3. 保持手机连接当前 Wi-Fi，并允许局域网/附近设备相关权限。

## Windows

1. 从系统托盘右键彻底退出旧版。
2. 完整解压 `猛人快传-windows-x64-v1.7.3.zip`，不能只复制 EXE。
3. 在新目录右键运行 `enable_lan_access.cmd`，允许更新 UDP 53317 和 TCP 53318 防火墙规则。
4. 启动 `lan_transfer.exe`，确认标题和文件版本为 `1.7.3+16`。

## 本次重点回归

1. 四屏电脑使用网线、手机和笔记本使用 Wi-Fi，打开所有设备上的 v1.7.3。
2. 等待约 5–10 秒或点击刷新，确认手机端的“四屏电脑”显示“局域网直连”。
3. 确认四屏电脑重新显示“魅族17”；如自动广播被路由器拦截，从任意一端再次扫码后应立即恢复显示。
4. 四屏电脑和两台手机分别双向发送文字、图片和一个大文件，观察直连路线、进度、速度和停止按钮。
5. 如果直连暂时不可达但二维码会话在线，发送应自动回退二维码本地连接，不能绕行 VPS。

## 网络说明

网线和 Wi-Fi 接入本身不妨碍局域网直连，只要路由器允许有线与无线设备互通。某些路由器会过滤跨有线/Wi-Fi的 UDP 广播；这种情况下二维码连接是正常的局域网兜底，不会使用公网流量。

公网功能继续使用原来的自建中转地址、访问令牌和家庭加密口令，VPS 服务端不需要因 v1.7.3 更新。

# 猛人快传 v1.8.4 安装与测试说明

v1.8.4 修复手机端一键更新下载不动：手机改为和浏览器一样使用系统代理下载，下载进度显示速度。其他功能、设置、聊天记录和已配对设备都不变。

## 安装

- **电脑**：在「设置 → 软件更新 → 检查更新」一键升级（程序在原文件夹里替换）。
- **手机**：手机上的 v1.8.3 及更早版本没有这个修复，这一次要手动安装：用电脑上的猛人快传把 `猛人快传-android-v1.8.4.apk` 发到手机，点文件气泡安装；或用浏览器从 GitHub 发布页下载。签名与之前相同，直接覆盖安装，数据保留。

## 实测手机一键更新（更新测试版）

`猛人快传-android-v1.8.4-更新测试版.apk` 带着这次的修复，但假装自己是旧版本，所以会把 GitHub 上当前的最新正式版当成新版本来下载安装，用来马上验证修复是否有效。只用于测试，不发布。

1. 手机保持代理开启。用电脑上的猛人快传把更新测试版发到手机并安装（标题会显示「更新测试版」）。
2. 打开「设置 → 软件更新 → 检查更新」，点「立即更新」。
3. 应看到下载进度和速度（例如几 MB/s），下载完成后弹出系统的安装确认，点「更新」。第一次会要求允许「安装未知应用」。
4. 装好后标题恢复为正式版（不再带「更新测试版」），聊天记录和设置都在。
5. 如果仍然失败，请在「设置 → 诊断」导出诊断日志发给开发者，看 `update_network proxy=` 这一行：显示代理地址说明已读到代理；显示 `none` 说明手机的代理模式没有对外提供系统代理。

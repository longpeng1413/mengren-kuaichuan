# 猛人快传 v1.10.1 安装与测试说明

v1.10.1 给聊天加上每日日期间隔，并把“发送被中途断开”的英文报错改成中文说明。协议不变，可与旧版本互传；设置、聊天记录和已配对设备都保留。

## 安装

- **已是 v1.8.0 以上**：「设置 → 软件更新 → 检查更新」一键升级。
- **Android**：也可以直接覆盖安装 APK。

## 测试

### 每日日期间隔

打开有几天聊天记录的对话：每天第一条消息上方有一条居中的灰色日期——今天的显示“今天”，前一天“昨天”，一周内“星期几”，更早“11月3日”，往年“2025年11月3日”。同一天的消息之间不重复显示；气泡上仍然显示具体时间。

### 发送被中途断开时的提示

如果电脑上开着 AdGuard 并且过滤猛人快传，发送大文件时可能被断开：

- 刚开始就被断开：程序会自动重试两次，大多数情况下你感觉不到；仍然失败时提示“连接被中途断开，文件还没有发出；可能被 AdGuard、杀毒软件或防火墙等拦截……”。
- 文件全部发出后才断开：提示“文件已全部发出，但没收到对方的确认：对方可能已经收到……”，请先在对方那边看看有没有收到再决定重发。
- 根本解决：AdGuard → 设置 → 网络 → 应用程序管理，找到猛人快传，关闭“通过 AdGuard 路由流量”。使用帮助的“连接注意事项”里也写了。

出问题时导出诊断日志，看 `send_failed` 记录。

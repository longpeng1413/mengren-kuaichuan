# 猛人快传 v1.7.7 修复候选版：安装与测试

当前候选包 `1.7.7+25` / `v1.7.7-rc.2`，在后台修复基础上增加文字/链接选取复制和中文程序名，本轮交互修复及 Windows 后台连续几天正常使用均已由用户确认。历史候选版为 `1.7.7+24` / rc.1；正式基线 v1.7.6 保留，休眠/网络恢复与 Android 稳定性全面回归仍待明确确认。发布附件与用户已确认测试包完全一致，附件内说明记录的是打包时状态，以本页和 Release 最新状态为准。

## Windows

1. 先彻底退出旧软件；旧版已卡死时可在任务管理器结束对应 `lan_transfer.exe`，不要删除聊天或接收文件。
2. 完整解压 `猛人快传-windows-x64-v1.7.7-rc.2.zip` 至固定目录。不能单独复制 EXE；程序、DLL 和 data 必须在一起。旧英文目录和 rc.1 包保留，不要把两版的 data/DLL 混放。
3. 运行一次包内 `enable_lan_access.cmd`，按系统提示确认。防火墙规则绑定 EXE 绝对路径，移动目录或升级到新目录后需重跑；仅切换 Wi-Fi 不需要。
4. 双击 `猛人快传.exe`。窗口和设置显示 v1.7.7；数据目录与旧版相同，正常保留历史和设置。先彻底退出旧版，否则单实例会恢复旧窗口。原开机自启动若指向旧目录，需要在新版设置中关闭后重新开启一次。
5. “×”关闭只是隐藏到托盘；单击托盘图标或再次运行快捷方式恢复窗口；右键托盘选择“彻底退出”才结束进程。

## Android（共享发现服务回归包）

- 文件 `猛人快传-android-v1.7.7-rc.2.apk`；包名与升级证书保持不变，构建号 25 高于 v1.7.6 的 23 和 rc.1 的 24，可覆盖安装，不要先卸载旧版。
- 此次重点为 Windows，但共用 UDP 代码有稳定性保护，因此提供 Android 对应包供回归。手机旧版 v1.7.6 仍可与 Windows 候选版通信，协议未变；不强制要求同时升级手机。

## 连接、速度与公网

- 同 Wi-Fi/手机热点自动发现；发现失败可扫码或手动 IP 配对。多级路由/访客网络隔离会影响直连。
- 热点传大视频/大文件优先 5 GHz，设备靠近并关闭兼容/省电模式。2.4 GHz 可能只有约 8 MiB/s；既有双手机实测 5 GHz 达约 60–70 MB/s，不保证所有设备均达到。
- 局域网优先；远程设备显示“公网 VPS 中转”。所有设备使用同一中转地址、访问令牌和家庭加密口令；本次无须更换或升级 VPS。
- 公网任意单文件不超过 200 MiB，文字、链接、图片、视频、APK、压缩包均可；传输可以停止并清理未完成文件。远端在线并处理确认后才算发送成功，尚无可靠离线消息。

## 请重点测试

- Windows：鼠标左键按住链接并拖动选取，然后右键“复制选中内容”；直接右键也可“复制全部”。手机：长按链接出现选择手柄，调整两端范围后复制选中内容，或直接复制全部。普通文字也支持这些操作；单击完整 HTTP/HTTPS 链接仍打开浏览器，拖选/长按不打开。
- 将内容粘贴到记事本/手机输入框核对完整链接、选中片段、中文与换行。手机选择手柄拖动的实机体验尚待确认。

1. 短时隐藏/恢复、重复点击快捷方式，确认只有一个主进程。
2. 后台至少一夜，再恢复窗口；重复测试休眠/唤醒和网络恢复，不要仅看刚启动时正常。
3. 手机与电脑双向发文字、小图片、APK/视频，测试停止发送。
4. 右键托盘“彻底退出”，确认能退出并再次启动。
5. 仍无响应时先保留现场，记录发生时间、是否刚唤醒/换网；可从设置导出诊断日志，或让开发代理读取当前进程，不需清除用户数据。

候选版的自动化验证与校验值见 `开发交接说明-v1.7.7.md`。候选转正式需完成上述实机回归。

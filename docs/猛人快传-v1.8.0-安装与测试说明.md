# 猛人快传 v1.8.0 安装与测试说明

v1.8.0 新增「检查更新」和「一键自动更新」，Android 和 Windows 都有。设置、聊天记录和已配对设备都会保留。

## 安装 v1.8.0

### Windows

1. 在右下角托盘的猛人快传图标上右键「彻底退出」旧版。
2. 把压缩包解压到**原来的文件夹**并覆盖（推荐），或者新文件夹。桌面快捷方式指向 `猛人快传.exe`。
3. 换了文件夹后，如果手机发现不了电脑，右键 `enable_lan_access.cmd` →「以管理员身份运行」。
4. 检查：窗口标题为 v1.8.0。

### Android

直接覆盖安装 APK（签名与之前相同）。

## 新功能怎么用

- 打开「设置 → 软件更新」：
  - 「自动检查更新」默认打开，每天最多检查一次，只向 GitHub 查询版本号，不上传聊天或文件。
  - 「检查更新」可以随时手动检查。
  - 「清空更新缓存」显示更新文件占用的空间；下载的安装包和临时文件每次启动也会自动清理。
- 发现新版本时会弹窗，可选「立即更新」「以后再说」「跳过此版本」。
- 下载完成后先核对 SHA-256 校验值（相当于文件的身份证号），不一致就删除、不安装。
- **Android**：第一次更新时系统会要求允许猛人快传「安装未知应用」，打开开关后返回，会自动继续；然后在系统窗口里点「更新」。
- **Windows**：软件会自动关闭、替换文件、几秒后自动重新打开；防火墙规则和开机自启不受影响。替换失败会自动还原旧版本，重新打开后会提示。
- 如果程序放在 `Program Files` 这类不允许写入的文件夹，或者 GitHub 连不上，会提示原因，并提供「去网页手动下载」。

## 一键更新的实测方法（可选）

正式发布下一个版本之前，可以用「更新测试版」把整个一键更新流程真实跑一遍。更新测试版假装自己是 v1.7.0，所以会把 GitHub 上当前的正式版（v1.7.8）当成新版本，下载并安装它。跑完后设备会回到干净的 v1.7.8 正式版，数据都保留，再安装 v1.8.0 正式包即可。

### Android

1. 覆盖安装 `猛人快传-android-v1.8.0-更新测试版.apk`（标题会显示「更新测试版」）。
2. 打开「设置 → 软件更新 → 检查更新」，应提示发现 v1.7.8，点「立即更新」。
3. 观察：下载进度 → 系统要求「允许安装未知应用」（第一次）→ 返回后系统弹出更新确认 → 点「更新」。
4. 装好后标题变为「猛人快传 v1.7.8」，聊天记录和设备仍在。
5. 最后覆盖安装 `猛人快传-android-v1.8.0.apk` 正式包。

### Windows

1. 退出正在运行的猛人快传，把 `猛人快传-windows-x64-v1.8.0-更新测试版.zip` 解压到一个**单独的新文件夹**。
2. 运行其中的 `猛人快传.exe`，「设置 → 软件更新 → 检查更新」，点「立即更新」。
3. 观察：下载 → 解压 → 程序关闭 → 几秒后自动重新打开，标题变为 v1.7.8，并提示「已更新到 v1.7.8」。
4. 测完先「彻底退出」，删除这个测试文件夹，再打开正式文件夹里的 v1.8.0。
   如果开了「开机自启动」，测试期间它会临时指向测试文件夹；重新打开一次正式版就会自动指回来。

遇到问题时，请在「设置 → 诊断」导出诊断日志发给开发者，日志中以 `update_` 开头的记录就是更新过程。

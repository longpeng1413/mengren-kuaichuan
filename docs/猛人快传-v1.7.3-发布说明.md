# 猛人快传 v1.7.3 发布说明

v1.7.3 专门修复有线 Windows 与 Wi-Fi 手机之间的局域网发现、已移除设备重新添加和路线选择。公网加密协议仍为 3，VPS 不需要重新部署。

## 主要变化

- Windows 不再把所有局域网猜成 `/24`，可正确处理 `/23` 等真实子网。
- 对方手动扫码重新连接，或用户接受其新文件后，会从“已移除设备”中恢复。
- 同时存在直连和二维码通道时优先局域网直连，失败自动回退二维码连接。
- 保留二维码作为路由器拦截 UDP 广播时的本地兜底；“二维码本地连接”仍然只走局域网，不经过 VPS。

## 升级提示

- Android 请覆盖安装，保留设备身份、聊天记录和VPS设置。
- Windows 请从托盘右键彻底退出旧版，完整解压新 ZIP，并在新的解压目录重新运行一次 `enable_lan_access.cmd`，因为防火墙规则绑定具体 EXE 路径。
- 建议参与测试的 Android 与 Windows 都升级到 v1.7.3。

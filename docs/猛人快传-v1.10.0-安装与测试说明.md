# 猛人快传 v1.10.0 安装与测试说明

v1.10.0 新增消息长按菜单（复制、转发、引用、删除）、输入框粘贴图片和文件、图片消息只显示小缩略图、电脑静默启动。局域网/公网协议不变，可以和旧版本互传；设置、聊天记录和已配对设备都保留。

## 安装

- **已是 v1.8.0 以上**：「设置 → 软件更新 → 检查更新」一键升级（正式发布后）。
- **测试阶段**：电脑先彻底退出猛人快传（托盘右键 → 彻底退出），把新包里的文件覆盖进原来的程序文件夹；Android 直接覆盖安装 APK。

## 测试

### 长按菜单

1. 手机上长按一条文字：选择菜单里应有“复制、转发、引用、删除、全选”（放不下的在“⋮”里）；电脑上右键文字同样。
2. 长按（电脑右键）图片或文件：弹出“转发、引用、删除”；电脑上还有“复制”“在文件夹中显示”，手机上有“保存位置”。
3. **复制**：电脑上复制一张收到的图片，粘贴到微信、画图或文件夹里都应可以。
4. **转发**：选另一台设备 → 发送。文字直接发出并提示“已转发给 …”；文件会切换到那台设备的对话里显示进度，可以停止。选离线设备时会排队。
5. **引用**：输入框上方出现“引用 名字：内容”，发出后自己和对方（新版）都显示为回复 + 下方灰色引用框；旧版本收到的是“「名字：内容」+ 分隔线 + 回复”的普通文字。
6. **删除**：确认后只从本机聊天记录删除，已保存的文件还在。

### 粘贴图片和文件

1. 电脑：截图（Win+Shift+S）后在输入框按 Ctrl+V，应弹出“发送给 …”并显示截图预览，点发送。
2. 电脑：在资源管理器里复制一个压缩包或几张图片，在输入框按 Ctrl+V（或右键 → 粘贴文件），确认后发送。复制普通文字后 Ctrl+V 仍应粘贴成文字。
3. 手机：在相册或浏览器里“复制图片”，回到猛人快传长按输入框，应出现“粘贴图片”。Gboard 等支持发图片的输入法，在它的剪贴板面板里点图片也可以发送。
4. 设置 → 常规 → “发送缓存”显示粘贴的截图占用的空间，可以清空。

### 图片小缩略图

聊天里的图片只显示一张圆角小图，不显示文件名、大小和保存位置；点一下用系统看图打开。手机收到的图片现在也有缩略图了（以前只显示文件名）。

### 电脑静默启动

1. 设置 → 常规：打开“开机自启动”后出现“静默启动”（默认开）。
2. 注销或重启电脑：登录后不弹窗口，只在任务栏右下角托盘里有图标；用手机给电脑发文字应能收到；点托盘图标打开窗口。
3. 关掉“静默启动”再重启，开机后应正常弹出窗口。

出问题时导出诊断日志。相关记录：`chat_forward`、`chat_message_deleted`、`clipboard_files_copied`、`outgoing_cache_cleaned`、`app_start … silent=true`。

# 猛人快传 v1.11.3

- **图片在猛人快传里预览**：以前点聊天里的图片会交给系统看图软件，每点一次就多开一个窗口。现在像微信一样在软件里全屏预览，同一时间只会打开一个；支持缩放（电脑滚轮、手机双指、双击放大），用 ← → 或左右滑动切换这个对话里的其他图片，Esc 或返回键关闭。需要时可以点右上角“用其他应用打开”，电脑上还能“在文件夹中显示”。
- **设置页的版本信息移到最上面**：打开设置就能看到当前版本号、作者和 GitHub 项目主页链接。
- 本版手机和电脑都更新。

## 下载

已安装 v1.8.0 及以上的，在「设置 → 软件更新」点「检查更新」即可一键升级。

- Android：`mengren-kuaichuan-android-v1.11.3.apk`，直接覆盖安装（签名与之前版本相同）。
- Windows：`mengren-kuaichuan-windows-x64-v1.11.3.zip`。

校验值见 `SHA256SUMS-v1.11.3.txt`。程序没有数字签名，Windows 或安全软件可能会提示，选择「仍要运行」即可。

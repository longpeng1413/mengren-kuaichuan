# 猛人快传 v1.11.0 安装与测试说明

v1.11.0 新增语音消息、语音转文字和语音输入。语音识别完全在本机离线完成，第一次使用时下载约 229 MB 的识别模型。协议不变，可与旧版本互传（旧版收到的语音是一个可播放的音频文件）。

## 安装

- **已是 v1.8.0 以上**：「设置 → 软件更新 → 检查更新」一键升级。
- **Android**：也可以直接覆盖安装 APK。第一次录音时会请求麦克风权限。
- **Windows**：如果录音提示无法使用麦克风，到「Windows 设置 → 隐私和安全性 → 麦克风」打开“允许桌面应用访问麦克风”。

## 测试

### 语音消息

1. 打开对话，**按住**输入框左边的麦克风按钮说话，上方显示“正在录音 0:03 · 松开发送，上滑取消”；松开即发送。
2. 再按住说话，手指**向上滑**，提示变红“松开手指，取消发送”，松开后不发送。
3. 按一下就松开（不到 1 秒）：提示“说话时间太短”。
4. 对方收到一条“▶ 5″”样式的语音条，点一下播放、再点停止；同一时间只播放一条。
5. 超过 60 秒自动发送。
6. 旧版本（v1.10.x 及以前）收到的是名为“语音消息_日期_时间_5s.wav”的文件，点开可以用系统播放器听。

### 语音转文字

1. 长按语音条 → “转文字”。第一次会提示下载识别模型（约 229 MB），点“下载”，显示进度和速度，可取消；取消后再下载会从断点继续。国内网络可能需要打开代理。
2. 下载完成后自动开始识别，文字显示在语音条下方。长按 → “隐藏文字”可以收起。
3. 设置 → 常规 → “语音识别模型”显示已下载大小，可删除；“语音消息”显示录音占用空间，可清空。

### 语音输入

**点一下**麦克风按钮（不是按住）：上方显示“正在听写 · 再点一次麦克风结束”。说完再点一次，说的话变成文字填进输入框，可以修改后再发送。

出问题时导出诊断日志，相关记录：`voice_received`、`speech_model_download_*`、`speech_worker_started`、`speech_worker_start_failed`。

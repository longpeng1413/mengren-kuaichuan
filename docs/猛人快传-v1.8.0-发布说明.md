# 猛人快传 v1.8.0

**新增检查更新与一键自动更新**（Android 和 Windows 都支持）。从这一版开始，以后出新版本时，猛人快传会自己提醒你，点「立即更新」就能装好，不用再手动下载、解压、改快捷方式。

- 设置里新增「软件更新」：自动检查开关（默认打开，每天最多查一次）、「检查更新」按钮、更新缓存占用和一键清空。
- 发现新版本时会显示更新说明，可以选「立即更新」「以后再说」或「跳过此版本」。下载可以随时取消。
- 下载完成后先核对安装包的 SHA-256 校验值（相当于文件指纹），对不上就删除，不会安装。
- Android：交给系统安装器覆盖安装。第一次会要求允许「安装未知应用」，打开开关返回后自动继续。
- Windows：自动关闭、替换程序文件、几秒后重新打开，并提示已更新到哪个版本。替换出错会自动还原旧版本。程序位置不变，所以防火墙放行和开机自启不受影响。使用系统代理的电脑也能正常访问 GitHub。
- 只向 GitHub 查询版本信息，不会上传聊天记录或文件。

局域网和公网协议、VPS 中转、聊天记录、已配对设备都不变。

## 下载

- Android：`mengren-transfer-android-v1.8.0.apk`，直接覆盖安装（签名与之前版本相同）。
- Windows：`mengren-transfer-windows-x64-v1.8.0.zip`，解压后双击 `猛人快传.exe`。

## 从 v1.7.x 升级

旧版本没有自动更新功能，这一次需要手动升级；装好 v1.8.0 之后，以后的版本就可以在软件里一键更新。

Windows：

1. 在右下角托盘的猛人快传图标上右键「彻底退出」。
2. 把新版解压到新文件夹，桌面快捷方式改为指向新的 `猛人快传.exe`。
3. 防火墙规则绑定的是程序路径。如果手机发现不了电脑，右键 `enable_lan_access.cmd` →「以管理员身份运行」。

校验值见 `SHA256SUMS-v1.8.0.txt`。程序没有数字签名，Windows 或安全软件可能会提示，选择「仍要运行」即可。

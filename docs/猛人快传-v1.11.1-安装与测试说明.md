# 猛人快传 v1.11.1 安装与测试说明

v1.11.1 修复电脑端按住麦克风或点语音输入时提示“无法开始录音：……指定的对象或值不存在”。协议、设置和聊天记录不变。

## 安装

- 「设置 → 软件更新 → 检查更新」一键升级；Android 也可以直接覆盖安装 APK。

## 测试

1. 电脑端打开对话，按住麦克风说两三秒，松开：应发出一条“▶ 3″”样式的语音，不再报错。
2. 点一下麦克风说一句话，再点一下：说的话变成文字填进输入框（第一次会提示下载识别模型）。
3. 对方点语音条能播放；长按（右键）选“转文字”能显示文字。
4. 如果仍提示无法使用麦克风，到“Windows 设置 → 隐私和安全性 → 麦克风”确认“允许桌面应用访问麦克风”已打开，并确认电脑有可用的麦克风。

出问题时导出诊断日志发给开发者。

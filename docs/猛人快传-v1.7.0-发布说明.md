# 猛人快传 v1.7.0 发布说明

v1.7.0 在保留 Android 与 Windows 局域网高速直传的基础上，新增用户自有 VPS 的端到端加密公网中转。

## 主要更新

- 支持在线远程文字和 HTTP/HTTPS 链接。
- 支持通过公网发送单个不超过 200 MiB 的图片、视频、APK、压缩包、文档和其他文件。
- 公网文件使用 256 KiB 分块和 AES-GCM-256 端到端加密；VPS 不保存文件，也不能读取正文。
- 发送成功必须等待接收端完成解密和保存，不再把“VPS 已接收”误报为“对方已收到”。
- 界面明确显示“局域网直连”“二维码本地连接”或“公网 VPS 中转”，本地路线始终优先。
- 公网文件传输可以随时停止，接收端会清理未完成的 `.part` 文件。
- VPS 访问令牌和家庭加密口令保存在系统安全存储，并提供显示按钮和家庭口令校验码。
- 设置页补充手机热点、二维码兜底和 5 GHz 高速传输说明。

## 安装与升级

- Android 应直接覆盖安装 APK，不要先卸载，以保留设置和聊天记录。
- Windows 必须完整解压 ZIP 后运行 `lan_transfer.exe`，不能只复制 EXE。
- 所有参与公网传输的设备必须升级到 v1.7.0；旧测试版使用不同公网协议，不能混用。
- 原有中转地址、VPS 访问令牌和家庭加密口令不需要更换。

详细步骤见 [安装与使用说明](猛人快传-v1.7.0-安装与使用说明.md)。

## 已知限制

- 公网首版要求双方在线并保持软件运行，尚无离线消息和可靠后台通知。
- 公网单文件上限为 200 MiB，暂不支持断点续传和公网点对点加速。
- 公网经美国 VPS 中转时，速度受双方上行、跨境延迟和 VPS 带宽影响。
- 用户曾在测试版 11 观察到偶发界面无响应，目前尚未在正式构建中复现；如再次发生，请在重启前记录操作步骤，重启后从设置页导出诊断日志。

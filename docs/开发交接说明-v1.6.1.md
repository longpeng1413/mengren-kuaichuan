# 猛人快传 v1.6.1 开发交接说明

## 1. 项目目标与本版边界

“猛人快传”是 Android 与 Windows 之间的个人局域网传输工具。本版新增 Android 手机热点互传，不依赖公司/家庭路由器，也不经过互联网。

- 支持 Android、Windows，不新增其他客户端。
- 保留文字、链接、图片、视频、大文件、二维码配对、自动发现、诊断日志和发送取消。
- v1.6.1 不包含 VPS、公网中转、账号系统或云存储；这些属于后续版本。
- 手机热点本身会形成局域网：手机 A 开热点、手机 B 连接后，两台手机可以双向传输。

## 3. v1.6.1 热点互传实现

### Android 网卡枚举

`MainActivity.kt` 通过已有 MethodChannel 新增 `networkInterfaces` 方法，使用 `java.net.NetworkInterface` 返回：

- 网卡名；
- IPv4 地址；
- 真实网络前缀长度；
- 系统提供的广播地址。

这能覆盖不同厂商使用的 `ap0`、`wlan0`、`swlan`、`softap` 等热点/Wi-Fi 接口，不写死 `192.168.43.0/24`。

### UDP 自动发现

`LocalNetworkService` 过滤蜂窝网络和常见 VPN 接口，并对热点/Wi-Fi 地址优先排序。`DiscoveryService` 每两秒向以下目标发送同一份发现消息：

1. `255.255.255.255`；
2. 每个活动本地网卡按真实前缀计算的定向广播地址。

单个广播目标失败不会阻断其他目标。网卡拓扑变化、目标失败和 UDP Socket 状态会写入诊断日志。

### 二维码兜底

二维码页面不再假定扫码方只能是手机、展示方只能是电脑：

- 任意一台 Android 手机都可以展示二维码；
- 另一台手机点击“扫描另一台设备二维码”；
- 可刷新热点和局域网地址；
- 多网卡时可以选择正确的热点/Wi-Fi 地址；
- 自动发现被系统或厂商限制时，二维码和手动 IP 仍能建立双向 WebSocket。

## 4. 权限与新系统兼容

- Manifest 保留 `INTERNET`、`ACCESS_WIFI_STATE`、`CHANGE_WIFI_MULTICAST_STATE`，新增 `ACCESS_NETWORK_STATE`。
- 当前 targetSdk 为 36。Android 官方说明 SDK 36 及以下仍通过 `INTERNET` 隐式获得局域网访问，因此本版不应提前声明或请求 `ACCESS_LOCAL_NETWORK`。
- 将来升级到 targetSdk 37（Android 17）时，必须声明并在运行时请求 `ACCESS_LOCAL_NETWORK`，同时处理拒绝和撤销。

官方说明：`https://developer.android.com/privacy-and-security/local-network-permission`

## 5. 设置内使用说明

设置页底部新增“连接与高速传输”区域，Android 和 Windows 均可见：

- 手机热点互传步骤与自动发现失败时的二维码/手动 IP 兜底；
- 大文件优先使用 5 GHz 热点、关闭兼容模式并让设备靠近；
- 同协议版本、Windows UDP 53317/TCP 53318 放行和诊断日志要求。

用户双手机实测确认：2.4 GHz 热点稳定约 8 MiB/s，切换 5 GHz 后达到 60–70 MB/s，因此原速度不是软件限速。

## 7. 实机验证结果与后续复测

两台 Android 手机已确认热点网络下可以传输文字和文件，并确认 5 GHz 可显著提升大文件速度。不同厂商仍建议按以下步骤复测：

1. 手机 A 打开热点，手机 B 连接；两台都确认显示 v1.6.1。
2. 等待自动发现，分别发送一条文字和一张图片。
3. 如果没有自动出现设备，在 A 显示二维码、B 扫码，然后测试 A→B 和 B→A。
4. 交换热点角色，再重复测试。
5. 双向发送大文件，观察速度、停止按钮和接收端 `.part` 清理。
6. 失败时记录手机品牌、Android 版本、热点角色、发生时间，并从两台手机导出诊断日志。

## 8. 关键文件

- `app/lib/src/network/local_network_service.dart`：网卡模型、过滤、排序和广播计算。
- `app/lib/src/discovery/discovery_service.dart`：全局广播、定向广播和发现日志。
- `app/lib/src/pairing/pairing_page.dart`：手机热点说明、地址刷新和手机对手机扫码。
- `app/android/app/src/main/kotlin/com/personal/lantransfer/lan_transfer/MainActivity.kt`：Android 原生网卡枚举。
- `app/android/app/src/main/AndroidManifest.xml`：网络权限。
- `app/test/local_network_service_test.dart`：热点网络单元测试。
- `app/lib/src/settings/settings_page.dart`：连接、高速传输和故障排查说明。
- `app/lib/src/pairing/pairing_relay.dart`：配对协议 2 和双向 WebSocket，未改变协议。
- `app/lib/src/transfer/`：HTTP 直连传输，未改变协议。

## 9. 构建与发布

项目原路径含中文，运行前保证 `L:` 未被占用，然后使用：

```powershell
.\scripts\flutter.ps1 analyze
.\scripts\flutter.ps1 test
.\scripts\flutter.ps1 build apk --release
.\scripts\flutter.ps1 build windows --release
```

不要提交 `dist/`、`.tools/` 或 `private-signing/debug.keystore`。APK 必须继续使用现有签名，否则无法覆盖升级。

## 10. 后续规划

热点双手机实机回归已完成。下一步规划 v1.7.0 的 VPS 远程文字、链接和图片；公网功能应使用独立传输层和端到端加密，不应修改或破坏当前 LAN 协议。

所有会话和传输必须明确显示当前路线：`局域网直连`、`二维码本地连接`、`公网 VPS 中转`，以后增加点对点时显示 `公网点对点`。公网发送图片以及未来的大文件时必须显示速度、进度和流量，并始终允许发送端手动停止；停止后服务端和接收端要清理未完成内容。

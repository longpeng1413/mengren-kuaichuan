# 猛人快传 v1.10.1

- **聊天记录按天分隔**：像微信一样，每天第一条消息上方显示一条居中的日期——今天、昨天、星期几、11月3日，往年带上年份。翻看历史消息时一眼就知道是哪一天发的。
- **发送被中途断开时说清楚原因**：以前只显示一句英文“Connection closed before full header was received”。现在：
  - 文件还没开始传就被断开时，自动重试两次，大多数情况下直接发成功；
  - 仍失败时用中文说明“可能被 AdGuard、杀毒软件或防火墙等拦截，可在该软件里把猛人快传设为不过滤”；
  - 文件已经全部发出、只是没收到确认时，提示“对方可能已经收到，请先在对方那边确认”，避免重复发送。
- 使用帮助“连接注意事项”补充了 AdGuard 的设置方法。

## 下载

已安装 v1.8.0 及以上的，在「设置 → 软件更新」点「检查更新」即可一键升级。

- Android：`mengren-kuaichuan-android-v1.10.1.apk`，直接覆盖安装（签名与之前版本相同）。
- Windows：`mengren-kuaichuan-windows-x64-v1.10.1.zip`。

校验值见 `SHA256SUMS-v1.10.1.txt`。程序没有数字签名，Windows 或安全软件可能会提示，选择「仍要运行」即可。

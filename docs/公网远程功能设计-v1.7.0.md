# 猛人快传 v1.7.0 公网远程功能设计

## 本版目标

v1.7.0 第一阶段只支持双方同时在线时，经用户自己的 VPS 发送文字、HTTP/HTTPS 链接和不超过 20 MiB 的图片。原有局域网传输协议保持版本 2，不与公网协议混用，也不改变 v1.6.1 的 Android 升级签名。

暂不包含离线消息、系统级可靠后台通知、视频、任意大文件、断点续传和公网点对点打洞。这些功能必须经过公网流量保护和实机回归后再逐步加入。

## 网络路线与用户控制

应用必须始终显示当前选中的路线：

- `局域网直连`：同一 Wi-Fi 或手机热点内直接传输。
- `二维码本地连接`：二维码建立的本地双向通道。
- `公网 VPS 中转`：跨地区在线密文中转，设备使用云图标。
- 后续若加入打洞，再增加 `公网点对点`，不能沿用模糊的“已连接”。

同一设备同时存在局域网和公网路线时，优先级为二维码本地连接、局域网直连、公网 VPS 中转，避免本可直连的数据绕行美国 VPS。

公网图片发送沿用聊天页的“停止发送”按钮。停止后发送端发送加密的 `cancel` 控制消息，接收端关闭文件流并删除对应传输目录中的 `.part` 文件。v1.7.0 禁止公网视频和其他大文件，避免误用移动数据或产生 VPS 流量费用。

## 安全模型

- 设备共享一个 12-256 位家庭加密口令；该口令只保存在 Android/Windows 系统安全存储中，绝不发送到 VPS。
- 使用 PBKDF2-HMAC-SHA256（210,000 次）派生设备对密钥，使用 AES-GCM-256 加密并校验消息完整性。
- 协议版本、消息 ID、发送方、接收方和发送时间进入附加认证数据，服务端不能静默修改这些字段。
- VPS 访问令牌用于阻止陌生客户端接入，但不能替代端到端加密。
- 公网应用配置只接受 `wss://`；VPS 上的 Dart 服务默认监听 `127.0.0.1:8080`，由 Caddy/nginx 终止 TLS。
- VPS 当前可以看到连接 IP、设备 ID、显示名称、在线时间、收发目标和密文大小；它看不到消息正文或图片内容。首版不宣称具备匿名性或元数据隐藏能力。

## 在线协议

- WebSocket 路径：`/v1/relay`
- 协议版本：1（与局域网 `protocolVersion = 2` 独立）
- 消息类型：`text`、`link`、`imageStart`、`imageChunk`、`imageEnd`、`cancel`
- 图片块：最大 256 KiB；图片总大小最大 20 MiB。
- 服务端只维护内存中的在线连接，收到合法密文后立即转发并回传 `relayed`。目标离线时立即返回 `recipient_offline`，不落盘、不排队。

## 已完成的自动验证

- 加密正文可正确解密，错误家庭口令和被篡改的认证数据会失败。
- 图片分块保持二进制内容，取消消息是独立的加密控制类型。
- 中转服务拒绝错误访问令牌，只向在线目标转发结构合法的加密信封。
- 两个远程客户端能发现彼此、等待中转确认并接收/解密链接。
- Flutter 设备合并确保同一设备的本地路线覆盖公网路线。

## VPS 部署进度

- 在线中转已部署到 Debian 12 VPS 的 Docker，容器只映射到 `127.0.0.1:18080`，健康检查和重启恢复正常。
- VPS 的 80/443 已由 Caddy 使用，原 `meng1314.top` 个人网站继续反向代理到 Ghost；部署过程中没有修改该站点。
- `zlp1314.top` 不在当前登录的 Cloudflare 账号域名列表中，已按用户授权使用第一个免费托管域名。
- 当前在线地址为 `wss://relay.meng1314.de5.net/v1/relay`；仅 DNS A 记录、Caddy 公开证书、健康接口、带令牌 WSS 握手和无令牌 HTTP 401 均已验证。
- 访问令牌和家庭口令不得记录在文档、日志或 Git；VPS 登录口令已在对话中暴露，发布前应由用户轮换，自动化改用独立 SSH 密钥。

仍需做郑州/安徽两地在线文字、链接、小图片、接近 20 MiB 图片和中途停止回归。通过后才能制作并发布 v1.7.0 安装包。

## 后续路线

1. v1.7.x：离线密文队列、有效期、容量上限、收件确认和删除策略。
2. Android 可靠后台通知：推送唤醒、通知权限、电池优化提示和厂商后台限制回归。
3. 远程大文件：明确显示公网路线、流量确认、分块校验、断点续传、暂停/取消和服务端限额。
4. 公网点对点加速：优先尝试直连，失败才回退 VPS；无论路线如何变化，界面必须实时显示且允许用户停止。

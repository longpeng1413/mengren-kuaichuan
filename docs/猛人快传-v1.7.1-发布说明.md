# 猛人快传 v1.7.1 发布说明

v1.7.1 是 v1.7.0 的远程大文件稳定性修复版，公网协议仍为 3，现有 VPS、域名、TLS、访问令牌和家庭加密口令都不需要更换或重新部署。

## 主要修复

- Android 公网加解密、JSON 和 Base64 改到常驻后台 isolate，长时间传输时界面仍可点击、滚动和停止。
- 公网文件由逐块停等改为最多 4 块有限流水发送，降低高延迟线路对速度的影响。
- 手机发送文件后立即显示 0% 起始进度，随后显示百分比、进度条、已传大小和实时速度。
- 接收端新增停止按钮；发送端与接收端都可取消，双方会清理未完成文件。
- 发送端取消可打断正在等待的分块回执，不再最多等待 25 秒。
- 发送端退出、断线或 45 秒没有新数据时，接收端自动结束并清理长期停留的“接收中”状态。
- 分块诊断日志降噪、进度约 10 Hz 限频，并加入 8 MiB 写盘背压，减少 Android 主线程、存储和内存压力。

## 安装文件

- Android：`猛人快传-android-v1.7.1.apk`
- Windows：`猛人快传-windows-x64-v1.7.1.zip`

Android 请直接覆盖安装，不要先卸载。Windows 请先从托盘“彻底退出”旧版，再完整解压新 ZIP；不能只复制 EXE。参与公网传输的手机和电脑都应升级到 v1.7.1。

## 仍需实机观察

- 中国优化线路的实际速度取决于手机上行、接收端下行、线路拥塞、TLS、VPS 带宽和设备加解密性能；有限流水能减少停等损失，但不能保证固定速度。
- 请重点用 100–200 MiB PDF 或视频测试双向进度、双方停止、强制退出发送端和 Android 长时间点击响应。

# 猛人快传 v1.9.1

- **对方不在线也能发**：手机切到后台、黑屏或者不在身边时，电脑上照样可以给它发文字和文件。内容会先排队，气泡下面显示“等待对方上线，上线后自动发送”；对方一打开猛人快传，就自动按顺序发过去。聊过天的设备离线时也会留在“附近设备”列表里（变灰，标“离线”），并显示“N 条待发送”。排队的内容可以随时点“取消”；最多 100 条，7 天没发出去会标为“未发送”。手机给电脑发也一样。
- **电脑端回车发送后可以接着打字**：不用再点一下输入框；打开对话时光标就在输入框里。
- **华为、荣耀等手机的后台接收**：设置 → 接收 → 后台持续接收打开后，多了一个“系统后台设置”，点一下直接跳到手机的自启动/后台管理页面（华为、荣耀、小米、OPPO、vivo、魅族）。华为手机需要在那里把猛人快传改成“手动管理”，打开允许自启动、关联启动、后台活动，否则一切到后台就会被系统冻结。使用帮助里写了详细步骤。

## 下载

已安装 v1.8.0 及以上的，在「设置 → 软件更新」点「检查更新」即可一键升级。

- Android：`mengren-kuaichuan-android-v1.9.1.apk`，直接覆盖安装（签名与之前版本相同）。
- Windows：`mengren-kuaichuan-windows-x64-v1.9.1.zip`。

校验值见 `SHA256SUMS-v1.9.1.txt`。程序没有数字签名，Windows 或安全软件可能会提示，选择「仍要运行」即可。

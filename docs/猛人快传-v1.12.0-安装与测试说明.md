# 猛人快传 v1.12.0 安装与测试说明

v1.12.0 让电脑上的图片在单独的「图片查看」窗口打开、手机上点一次放大再点一次关闭，并新增图片编辑。手机和电脑都更新，协议、设置和聊天记录不变。

## 安装

- 「设置 → 软件更新 → 检查更新」一键升级；Android 也可以直接覆盖安装 APK。

## 测试

### 电脑：图片查看窗口

1. 点聊天里的一张图片：弹出单独的「图片查看」窗口，默认 960×720 居中，标题栏显示「图片查看 - 文件名」。
2. 不关窗口，回到聊天再点另一张图片：不会多开窗口，已打开的窗口切到这一张并到最前面。
3. 顶部工具栏逐个试：置顶（再点取消）、上一张/下一张（或 ← →）、全部图片（缩略图，点一张跳过去）、放大/缩小（或滚轮、Ctrl+= / Ctrl+-）、原始大小（或双击图片）、旋转、复制（粘贴到微信试试）、另存为、在文件夹中显示、更多 → 用其他应用打开 / 全屏（F11，Esc 退出全屏）。
4. 拖动顶栏中间可以移动窗口，双击最大化；右上角最小化、最大化、关闭（Esc 也能关闭）。
5. 主程序完全退出（托盘 → 退出）后，图片查看窗口也会自动关闭。
6. 改变图片查看窗口的大小后，主窗口下次打开时的大小不受影响。

### 手机：点一次放大，再点一次关闭

1. 点聊天里的图片：全屏查看。
2. 再点一下图片：关闭，回到聊天（会稍等一下，用来区分双击）。
3. 双击放大、双指缩放、左右滑动切换仍然正常。

### 图片编辑（两端）

1. 入口：看图界面右上方的「编辑」（电脑也可以 Ctrl+E），或在聊天里长按/右键图片选「编辑」。普通文件的菜单里没有「编辑」。
2. 底部工具栏逐个试：镜像、裁剪（拖动框的边角，点「完成」；「取消裁剪」放弃）、画笔▾（画笔、箭头、直线、圆形、方框、实心框）、文字（点图片输入，可换字号；用文字工具可拖动已有文字）、粗细、橡皮、马赛克、颜色、撤销/恢复（电脑 Ctrl+Z / Ctrl+Y）、清除。
3. 「发送」：编辑后的图片发到当前对话（文件名「原名_编辑.png」），原图不变。
4. 「复制」：到微信里粘贴，出现的是编辑后的图片。
5. 「保存」：电脑选择保存位置；手机保存到「下载/猛人快传」。
6. 画过东西后点「取消」会问「放弃这次编辑？」。

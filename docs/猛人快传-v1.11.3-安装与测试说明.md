# 猛人快传 v1.11.3 安装与测试说明

v1.11.3 把聊天里的图片改为在猛人快传里预览（不再每点一次就打开一个新的系统看图窗口），并把设置页的版本、作者和项目主页移到最上面。手机和电脑都更新，协议、设置和聊天记录不变。

## 安装

- 「设置 → 软件更新 → 检查更新」一键升级；Android 也可以直接覆盖安装 APK。

## 测试

### 图片预览

1. 点聊天里的一张图片：在猛人快传里全屏显示。连续快速点两次也只会打开一个预览。
2. 电脑：滚动鼠标滚轮放大缩小，双击放大/还原，放大后拖动查看细节；按 ← → 或点两侧箭头切换这个对话里的其他图片，顶部显示“2 / 5”；按 Esc 或左上角 × 关闭。
3. 手机：双指缩放、双击放大，左右滑动切换图片，按返回键关闭。手机收到的图片（保存在系统下载里的）也能预览。
4. 右上角“用其他应用打开”可以交给系统看图软件；电脑上还有“在文件夹中显示”。
5. 已被删除的图片不出现在切换列表里，点它仍提示“文件已被移动或删除”。

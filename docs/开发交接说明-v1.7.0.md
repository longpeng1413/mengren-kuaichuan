## v1.7.0 已实现

- `packages/remote_protocol`：AES-GCM-256 加密信封、PBKDF2 密钥派生、在线客户端、远程设备状态、文字/链接/任意文件分块/取消消息。
- `relay_server`：带 Bearer 访问令牌的在线 WebSocket 中转；不落盘，目标离线立即拒绝；发送成功必须等待接收端处理回执。
- Flutter 设置页：默认关闭的 VPS 配置，正式配置强制 `wss://`，访问令牌和家庭口令使用系统安全存储。
- Flutter 设备和聊天页：明确显示局域网直连、二维码本地连接或公网 VPS 中转。
- 同设备路线合并：本地路线覆盖公网路线。
- 远程任意文件：单个最大 200 MiB、256 KiB 分块、进度显示和发送端停止；取消后接收端删除未完成目录和 `.part` 文件。
- 超过 200 MiB 的文件、断点续传和公网点对点加速仍未实现。

## 安全边界

- 家庭加密口令不能传给 VPS、写入普通 SharedPreferences、日志、Git 或安装说明。
- VPS 访问令牌也不能提交；部署时只通过环境变量 `MQT_RELAY_TOKEN` 注入。
- 客户端正式环境只接受 `wss://`。Dart 服务默认监听 `127.0.0.1:8080`，公网 TLS 由 Caddy/nginx 提供。
- 服务端能看到 IP、设备 ID、名称、时间、目标和密文大小，不能看到消息正文或文件内容。
- Android 更新必须继续使用原 `private-signing/debug.keystore`，该文件禁止提交。
- APK 已验证为 `1.7.0+13`、v2 签名，证书 SHA-256 仍为 `FE1C0C4965D1C29D66B6EFDE11F403525261152AB53E18E96AB36FEBFE495464`。

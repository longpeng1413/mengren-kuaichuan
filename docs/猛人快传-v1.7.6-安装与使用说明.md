# 猛人快传 v1.7.6 安装与使用说明

## Android 正式版升级

1. 可以先卸载名称为“猛人快传测试版”的独立测试应用。
2. 不要卸载手机上原有的 v1.7.5 正式版，否则可能丢失正式版保存的身份、设置和聊天记录。
3. 直接打开 `mengren-transfer-android-v1.7.6.apk`，覆盖安装 v1.7.5 正式版。
4. 安装后确认首页标题为“猛人快传 v1.7.6”，并检查原设备身份、设置、聊天记录和公网配置仍然存在。

## Windows

1. 从系统托盘右键彻底退出旧版。
2. 完整解压 `mengren-transfer-windows-x64-v1.7.6.zip` 到固定文件夹，不要只复制 EXE；升级时覆盖同一文件夹即可。
3. 在新目录运行一次 `enable_lan_access.cmd`，并在 Windows 用户账户控制中选择“是”。脚本会把防火墙规则绑定到当前程序路径，并覆盖公用、专用和域网络中的私有局域网地址；以后更换 Wi-Fi 无需重配。
4. 如果以后移动了解压目录，需要在新目录重新运行一次 `enable_lan_access.cmd`。
5. 启动 `lan_transfer.exe`，确认标题为“猛人快传 v1.7.6”。

## 建议回归项目

- 双方打开后等待 5–10 秒，确认 Android 与 Windows 持续显示对方。
- 分别发送一条文字和一个小文件，验证双向传输。
- 切换到另一个允许局域网设备互访的 Wi-Fi，确认无需重新配置防火墙。
- Android 从后台恢复、Windows 从睡眠恢复后，再次验证发现和双向传输。

如果 Wi-Fi 开启了客户端隔离、AP 隔离或 VLAN 隔离，局域网设备会被路由器禁止互访，任何纯局域网传输软件都会受到影响。

# 猛人快传 v1.11.0

- **语音消息**：按住输入框旁的麦克风说话，松开发送；手指上滑取消，最长 60 秒。对方收到“▶ 12″”样式的语音条，点一下播放。语音保存在猛人快传自己的文件夹里（不进下载文件夹），超过 30 天或总量超过 500 MB 自动清理，设置里可以查看和清空。
- **语音转文字**：长按语音条选“转文字”，文字显示在语音下方，可以复制。识别**完全在本机离线完成**，录音不会上传到任何服务器，也不需要注册账号。
- **语音输入**：点一下麦克风开始说话，再点一下结束，说的话变成文字填进输入框，改好再发。
- 识别使用开源的 SenseVoice 离线模型（中文、英文、粤语都能识别，自动加标点）。模型约 229 MB，第一次使用时从本项目 GitHub 发布页下载，可断点续传、下载后自动校验，设置里可删除。国内网络下载可能需要代理。
- 旧版本猛人快传收到的语音是一个可播放的音频文件，互传不受影响。
- 安卓安装包去掉了只在电脑模拟器上用的 x86_64 部分；因为带上了离线识别引擎，安装包从约 70 MB 变为约 90 MB。

## 下载

已安装 v1.8.0 及以上的，在「设置 → 软件更新」点「检查更新」即可一键升级。

- Android：`mengren-kuaichuan-android-v1.11.0.apk`，直接覆盖安装（签名与之前版本相同）。第一次录音时会请求麦克风权限。
- Windows：`mengren-kuaichuan-windows-x64-v1.11.0.zip`。

校验值见 `SHA256SUMS-v1.11.0.txt`。程序没有数字签名，Windows 或安全软件可能会提示，选择「仍要运行」即可。

# 猛人快传 v1.12.0 开发交接说明

版本 `1.12.0+40`（2026-11-11 构建），手机和电脑都要更新。协议、设置和聊天记录格式都没有改。

## 用户要求（2026-11-11）

1. 手机像微信一样：点一次图片放大查看，再点一次图片缩小（关闭）。
2. 电脑像电脑版微信一样：点图片打开一个单独的「图片查看」窗口，窗口里有编辑功能。
3. 加图片编辑，参考「猛人截图」（`D:\mengren-desktop`，PySide6，`ui/toolbar.py`、`ui/image_canvas.py`）和「猛人学习」（`D:\mengren-learning` 的 `app/core/shotedit.py`、`app/web/shotedit.js`）的编辑器。那两个是 Python 写的，猛人快传是 Flutter（Dart），所以按它们的工具和默认值用 Dart 重写，没有直接搬代码。
4. 文字识别（OCR）和翻译这次没做，留到以后。

## 电脑：单独的「图片查看」窗口

- **做法**：同一个程序再启动一份，带参数 `--image-viewer`（`image_view/viewer_protocol.dart` 的 `imageViewerArgument`）。聊天进程和看图进程通过标准输入/输出通信，每行一条 JSON，前缀 `MRKC:`（其他输出一律忽略）：
  - 聊天 → 看图：`ViewerShowCommand`（这个对话里所有还能显示的图片、点的是第几张、对方设备 ID 和名字、是否直接进编辑）。
  - 看图 → 聊天：`ViewerSendCommand`（对方设备 ID、编辑后图片的路径）。
- **只开一个窗口**：`DesktopImageViewerHost.instance`（`image_view/desktop_viewer_host.dart`）只启动一次进程，之后每次点图片只发一条显示命令，窗口切到那张并到前台（`AllowSetForegroundWindow` 让看图进程可以抢前台）。进程退出后下次点击会重新启动；管道写失败时自动重启一次。
- **跟着主程序退出**：看图进程监听标准输入，管道一关（主程序退出、崩溃）就 `exit(0)`。主窗口关闭只是隐藏到托盘，看图窗口不受影响。
- **原生入口**（`app/windows/runner/main.cpp`）：最先解析参数；看图模式跳过「已有窗口就激活它」和单实例互斥量（否则会被当成重复启动直接退出），窗口标题用 `猛人快传 图片查看`（**不能**以「猛人快传 v」开头，否则会被单实例检查当成主窗口），默认 960×720 居中，`set_remember_size(false)` 不覆盖主窗口记住的大小（`flutter_window.cpp` 的 `remember_size_`）。runner 源码仍保持纯 ASCII，中文用 `\u` 转义。
- **Dart 入口**（`app/lib/main.dart`）：最前面判断 `Platform.isWindows && isImageViewerLaunch(arguments)`，直接 `runImageViewerProcess()`，不初始化网络、托盘、诊断日志、设置。
- **窗口界面**（`image_view/desktop_viewer_app.dart` 的 `DesktopViewerPage`）：隐藏系统标题栏，自己画深色顶栏：置顶、上一张/下一张、全部图片（缩略图网格）、放大、缩小、原始大小/适应窗口、旋转、编辑、复制、另存为、在文件夹中显示、更多（用其他应用打开、全屏），中间显示「2 / 5 · 59%」并可拖动窗口，右边最小化/最大化/关闭。滚轮缩放、双击 1:1/适应、← →、Esc（全屏时先退出全屏）、F11、Ctrl+C/S/E、Ctrl+= / Ctrl+- / Ctrl+0。图片用 `ResizeImage` 限制最大 8192 像素解码，原始像素尺寸用 `ImageDescriptor` 读取（不解码整张）。
- **编辑后发送**：看图进程把编辑结果写进发送缓存 `OutgoingCache`（30 天 / 1 GiB，启动清理），把路径交给聊天进程；聊天进程 `app.dart _sendFromViewer` 按设备 ID 找到设备，和「转发」一样回到首页、打开那个对话自动发送（进度、离线排队、出错提示都和平时一样）。
- **测试环境**：`DesktopImageViewerHost.isAvailable` 在 `FLUTTER_TEST` 环境下为 false，组件测试里仍用软件内预览，不会真的启动第二个程序。

## 手机：单击关闭

- `chat/image_viewer.dart` 的 `ChatImageViewer` 新增 `closeOnTap`（聊天页传 `Platform.isAndroid`）：单击图片关闭，双击仍放大、双指缩放不变。因为要区分单击和双击，单击关闭会等约 0.3 秒。
- 顶部新增「编辑」按钮（`onEdit`）。电脑在独立窗口失败时也会退回这个软件内预览（同样有编辑按钮）。

## 图片编辑器（两端共用）

- `image_edit/edit_model.dart`：标注数据（画笔、箭头、直线、圆形、方框、实心框、文字、橡皮、马赛克）、撤销/恢复（最多 100 步）、镜像（标注和裁剪框一起翻转，文字只换位置不反向）、文字点选与橡皮擦文字、马赛克（方块大小 max(8, 长边/70)）、`renderEditPng` 按裁剪框输出 PNG。默认值照猛人截图：红色、粗细「中」5、字号「中号」24、加粗；粗细和字号按屏幕显示比例换算到图片像素，所以大图上画出来的粗细和看到的一致。
- `image_edit/image_editor_page.dart`：底部工具栏（镜像、裁剪、画笔▾、文字、字号▾、粗细▾、橡皮、马赛克、颜色、撤销、恢复、清除、复制、保存、发送、取消），Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z / Esc；画过东西后关掉会问「放弃这次编辑？」。**原图永远不改**。
- 输出：
  - 发送：写入 `OutgoingCache` 的 `原名_编辑.png`，发到当前对话（手机会先关掉预览回到对话）。
  - 复制：同样写入发送缓存后放到剪贴板（电脑可直接粘贴到微信等；手机用 content URI）。
  - 保存：电脑弹出「另存为」选位置；手机存到 `下载/猛人快传`（`ReceivedFileService.saveCopyToDownloads`，复用原生 `exportFile`，不删源文件）。
- 入口：手机预览顶部「编辑」；电脑看图窗口「编辑」或 Ctrl+E；聊天里图片消息长按/右键菜单「编辑」（电脑打开看图窗口并直接进编辑）。看图窗口里的编辑界面顶部有一条可拖动的标题条。

## 缓存与清理

- 编辑产生的文件只放 `OutgoingCache`（已有的启动清理：30 天、1 GiB 上限；删除消息/清空对话时一并删除），没有新建缓存目录。
- 看图进程不写日志、不写设置；窗口大小不记忆。

## 编译时遇到的坑

- 第一次编译电脑正式版后，看图窗口工具栏只有 4 个图标，其余空白：Flutter 的「图标字体瘦身」缓存没有按新代码重新生成，沿用了旧的 `MaterialIcons-Regular.otf`（只含旧图标）。删掉 `app/.dart_tool/flutter_build` 和 `app/build/flutter_assets` 后重新编译就正常了（字体 12072 → 14340 字节）。**以后新加图标后如果正式版里显示空白，先清这两个缓存目录再编译。**

## 设计

- **窗口**：`app/windows/runner/main.cpp` 的 `CenterOnPrimaryMonitor` 按主显示器工作区和 DPI 计算，默认 500×760（逻辑像素），工作区不够时缩到「工作区 − 40」，居中。`Win32Window::Create` 接收的是逻辑坐标。最小尺寸 380×520 在 `DesktopTrayService.initialize` 里用 `windowManager.setMinimumSize` 设置。不记忆上次窗口大小。
- **主题**：`app/lib/src/ui/app_theme.dart`。`ColorScheme.fromSeed` 用 `DynamicSchemeVariant.fidelity` 保住品牌红；但 fidelity 会把 `primaryContainer/secondaryContainer` 也做得很深（深红底黑字），所以统一覆盖成主色的浅色叠加（浅色模式 primary 12%，深色模式 inversePrimary 50%）。卡片无阴影、细描边、圆角 18；Windows 字体 `Microsoft YaHei UI`。
- **主界面**：`app/lib/src/ui/device_home_view.dart` 是纯展示组件，所有状态和回调仍在 `DeviceListPage`（`app.dart`）。路线圆点颜色固定，不随强调色变化。空状态是静态图形，不用无限动画（避免空闲耗电，也避免测试里 `pumpAndSettle` 卡住）。
- **设置页**：`_SettingsSection`（标题 + 卡片）、`_SettingsTile`（图标底块 + 标题 + 一行说明 + 右侧控件）、`_HelpTile`（可展开帮助）、`_ColorDot`。保留测试用的 Key：`update_section`、`check_update`、`removed_devices_summary`、`removed_device_<id>`、`restore_all_removed_devices`、`diagnostics_section`。底部图标用 144px 小图 `assets/icon/mengren_icon_small.png`（原图 1.9 MB 不打包）。
- **强调色**：新增 `AppThemeColor.ruby`（宝石红 `#B0283A`），默认值和读取失败的回退值都改为它。注意 `AppSettingsStore.save` 每次都会写入强调色，所以改过任何设置的老用户会保留原来的颜色。
- **桌面快捷方式**：`packaging/windows/创建桌面快捷方式.cmd`（纯 ASCII，调用同目录 ps1）+ `create_desktop_shortcut.ps1`（UTF-8 BOM，PowerShell 5.1 才能正确读中文）。快捷方式名「猛人快传.lnk」，目标、起始位置、图标都指向同文件夹的 `猛人快传.exe`；已有快捷方式会被替换并提示原目标。`-DesktopPath` 参数只用于测试。`scripts/package_windows.ps1` 负责复制进包。
- **附件命名**：`_pickInstaller` 依次找 `mengren-kuaichuan-…`、`mengren-transfer-…`，都没有时取该 Release 唯一的 .apk / 唯一含 windows 的 .zip。v1.8.0 只认旧名，靠这条回退找到 v1.8.1，所以每个 Release 每个平台只能放一个安装包。

## v1.8.2 补丁（2026-11-03）

- 版本 `1.8.2+29`。用户反馈两件事，并确认两台电脑都已从 v1.8.0 一键更新到 v1.8.1 成功。
- **二维码**：`app/lib/src/pairing/pairing_page.dart` 原来模块是黑色，但外层 `Card` 跟随主题，深色模式下成了黑底黑码，手机扫不出来。改为白色圆角 `Container`（12 px 内边距充当留白区）包住 `QrImageView`，并设 `backgroundColor: Colors.white`。以后不要让二维码背景跟随主题。
- **公网配置帮助**：`settings_page.dart` 的「使用帮助」第一条 `remote_setup_help`，`_HelpTile` 新增可选 `linkLabel/linkUrl`，用 `url_launcher` 打开 `_relayGuideUrl`（GitHub 上的 `docs/自建VPS中转指南-v1.7.2.md`，已确认仓库公开、地址有效）。改名或移动这份指南时必须同步这个地址。
- 验证：analyze 无问题，77 项测试通过；按 500×760 渲染了深色二维码页（白底黑码）和展开后的帮助，逐张检查。
- 安装包 SHA-256 见 `docs/SHA256SUMS-v1.8.2.txt`。
- 未实机验证：深色模式下手机实际扫码（需用户确认）；Android 上帮助链接打开浏览器。
- **窗口大小记忆**（同在 v1.8.2）：`app/windows/runner/window_size_store.{h,cpp}`。`FlutterWindow::MessageHandler` 在交给插件处理之前，于 `WM_EXITSIZEMOVE`（拖动调整结束）和 `WM_DESTROY`（彻底退出）时调用 `Save`：用 `GetWindowPlacement` 的 `rcNormalPosition`（最大化/最小化时也是还原大小）按显示器 DPI 换算成逻辑像素，写入 `HKCU\Software\MengrenKuaichuan` 的 `WindowWidth/WindowHeight`（DWORD）。`main.cpp` 启动时 `Load`，不合理的值（小于 380×520 或大于 10000）忽略；之后照样经过 `CenterOnPrimaryMonitor` 限制在屏幕内并居中。只记大小、不记位置（多显示器拔掉后不会开到看不见的地方）。没有记录时默认 750×760（用户要求比 500 宽 1.5 倍）。
- 实测（本机 1920×1032 工作区）：无记录时 750×760 居中；模拟拖成 900×650 后重开仍是 900×650 居中；最大化后关闭再开回到 900×650。测试写入的注册表值已删除。
- 本机安装位置（用户 2026-11-03 定）：先试过「每个新版本删旧文件夹、快捷方式指向新文件夹」，结果换文件夹后 Windows 防火墙重新弹出「是否允许公共网络和专用网络访问此应用」（放行规则按程序完整路径记录；其他猛人软件不监听入站连接所以不弹）。随即改为固定文件夹 `dist\猛人快传`（不带版本号），桌面快捷方式指向它，新版本原地升级。

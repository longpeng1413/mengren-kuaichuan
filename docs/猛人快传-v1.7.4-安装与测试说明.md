# 猛人快传 v1.7.4 安装与测试说明

## Android

1. 直接打开 `猛人快传-android-v1.7.4.apk` 覆盖安装，不要先卸载。
2. 确认标题为“猛人快传 v1.7.4”，原设置、设备身份和聊天记录仍保留。

## Windows

1. 从系统托盘右键彻底退出旧版。
2. 完整解压 `猛人快传-windows-x64-v1.7.4.zip`。
3. 在新目录运行一次 `enable_lan_access.cmd`，更新防火墙规则绑定的程序路径。
4. 启动 `lan_transfer.exe`，确认标题为“猛人快传 v1.7.4”。

## 本次重点回归

1. 等待设备自动连接。UDP 双向发现正常时显示“局域网直连”；使用保存的本地配对通道自动重连时显示“局域网安全连接”。两者都不经过 VPS。
2. 在任意设备会话中选择“移除设备”，确认它从列表隐藏。
3. 打开“设置 → 设备管理 → 已移除设备”，确认能看到名称与短标识。
4. 点击单台“恢复”，返回首页后等待数秒，确认设备重新出现；再测试“恢复全部设备”。
5. 双向发送文字和文件，确认局域网安全连接仍能处理路由器只允许单向新建连接的情况。

## 删除与恢复规则

“移除设备”表示用户主动隐藏并断开该设备，因此普通自动广播不会立即让它重新出现。需要恢复时，可从设置恢复、重新扫码连接，或者接受该设备新发来的文件。清空消息与缓存不会移除设备。

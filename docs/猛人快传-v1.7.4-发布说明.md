# 猛人快传 v1.7.4 发布说明

v1.7.4 修正局域网路线名称，并补齐已移除设备的可见恢复入口。公网协议仍为 3，VPS 不需要重新部署。

## 主要变化

- “二维码本地连接”更名为“局域网安全连接”。保存过的连接会自动重连，因此即使本次没有扫码也可能出现，这是正常的局域网连接，不使用公网流量。
- 设置新增“已移除设备”，可查看并恢复单台或全部设备。
- 用户主动移除后，设备不会因为下一次普通广播立刻重新出现；可从设置恢复、重新扫码，或在接受该设备的新文件时恢复。
- 同时存在 UDP 直连时仍优先显示和使用“局域网直连”；不可反向建连时使用安全连接保证双向发送。

## 升级提示

- Android 请直接覆盖安装，不要先卸载。
- Windows 请彻底退出旧版、完整解压新 ZIP，并在新目录重新运行一次 `enable_lan_access.cmd`。
- 建议参与互传的 Android 与 Windows 都升级到 v1.7.4。

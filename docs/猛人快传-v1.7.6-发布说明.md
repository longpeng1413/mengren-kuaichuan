# 猛人快传 v1.7.6 发布说明

## 本次修复

- 收到局域网设备公告后增加限频的单播公告回应，改善部分路由器或网卡只能单向传递 UDP 广播时，Windows 无法持续发现 Android 的问题。
- Windows 与 Android 均可导出诊断日志；日志包含发现、服务监听和传输阶段状态，但不记录聊天正文、文件内容、口令或令牌。
- Windows 防火墙配置脚本支持自提权并绑定当前解压目录中的 EXE；发布 ZIP 固定包含该脚本和安装说明。
- Android 连接 Windows 超时时，直接提示重新运行 `enable_lan_access.cmd`，方便识别防火墙规则仍绑定旧目录的情况。

## 升级说明

- Android 正式版使用与 v1.7.5 完全相同的升级证书，可直接覆盖安装并保留正式版数据。
- “猛人快传测试版”使用独立包名，可以在安装正式版前或安装成功后单独卸载。
- Windows 请完整解压到固定目录并运行一次 `enable_lan_access.cmd`；以后仅更换 Wi-Fi 无需重新运行，移动程序目录后才需要重新运行。
- 局域网配对协议与公网中转协议没有变更，现有 VPS 配置、访问令牌和家庭加密口令无需修改。

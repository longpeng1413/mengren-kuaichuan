# 猛人快传 v1.9.0 安装与测试说明

v1.9.0 新增“自动接收文件”和手机“后台持续接收”。协议不变，旧版本之间仍可互传；设置、聊天记录和已配对设备都保留。

## 安装

- **电脑、手机都已是 v1.8.0 以上**：在「设置 → 软件更新 → 检查更新」一键升级。手机如果下载不动，检查代理软件的“分应用代理”是否包含猛人快传。
- **第一次安装（Windows）**：解压到固定文件夹（不要放 `C:\Program Files`），双击「创建桌面快捷方式.cmd」，Windows 弹出防火墙提示时点「允许」。
- **Android**：直接覆盖安装 APK。

## 测试

### 自动接收（电脑和手机都要测）

1. 「设置 → 接收 → 自动接收文件」默认是“只限连接过的设备”。
2. 从一台你以前发过东西的设备发文件过来：应直接开始接收，不弹“接收文件？”。
3. 改成“每次都询问”再发：应弹确认框；改成“局域网内所有设备”再发：应直接接收。
4. 电脑端把窗口隐藏到托盘，从手机发文件：电脑应直接收下，打开窗口后对话里能看到。

### 手机后台持续接收

1. 「设置 → 接收 → 后台持续接收」打开：Android 13 及以上会请求“通知”权限，点允许；接着如果弹出“允许猛人快传后台运行？”，点“去允许”并在系统窗口里允许。
2. 通知栏应出现“猛人快传正在后台接收”。
3. 按 Home 键或返回键回到桌面（返回键不会退出），等 1 分钟，电脑上应仍能看到这台手机；从电脑发文字和文件，手机应弹出“收到 … 的消息/文件”通知，回到猛人快传能看到。
4. 熄屏 5 分钟后再从电脑发一次，手机应仍能收到。魅族等手机如果收不到，在系统「应用管理 → 猛人快传」里把耗电/后台设为“允许后台运行”，再试。
5. 关闭开关后，常驻通知应消失，切到后台后电脑上大约 7 秒后看不到这台手机（和以前一样省电）。

出问题时请在「设置 → 诊断」导出诊断日志。相关记录：`incoming_transfer_auto_accepted`（自动接收）、`device_trusted`（设备被记为连接过）、`background_receive_started/stopped`、`app_lifecycle_paused … keep_receiving=true`。

# 猛人快传 v1.12.0

- **电脑：图片在单独的「图片查看」窗口打开**（像电脑版微信）：点聊天里的图片会打开一个独立窗口，可以单独拖动、最大化、置顶、全屏（F11）。再点别的图片不会多开窗口，已打开的窗口直接切到那一张并到最前面。顶部工具栏有上一张/下一张、全部图片、放大、缩小、原始大小、旋转、编辑、复制、另存为、在文件夹中显示；滚轮缩放，双击在原始大小和适应窗口之间切换。
- **手机：点一次放大，再点一次关闭**（像手机微信）：双击和双指仍然可以缩放。
- **新增图片编辑**（参考猛人截图）：镜像、裁剪、画笔、箭头、直线、圆形、方框、实心框、文字（可选字号）、粗细、颜色、橡皮、马赛克、撤销/恢复、清除。编辑完可以直接发送给当前对话、复制（可粘贴到微信）或另存为新图片，**原图不会被修改**。入口：看图界面的「编辑」按钮（电脑 Ctrl+E），或在聊天里长按/右键图片选「编辑」。
- 本版手机和电脑都更新。

## 下载

已安装 v1.8.0 及以上的，在「设置 → 软件更新」点「检查更新」即可一键升级。

- Android：`mengren-kuaichuan-android-v1.12.0.apk`，直接覆盖安装（签名与之前版本相同）。
- Windows：`mengren-kuaichuan-windows-x64-v1.12.0.zip`。

校验值见 `SHA256SUMS-v1.12.0.txt`。程序没有数字签名，Windows 或安全软件可能会提示，选择「仍要运行」即可。

# 猛人快传 v1.8.2

小修复版，建议更新。

- **二维码永远白底黑码**：修复深色模式下二维码背景太暗、手机扫不出来的问题。现在二维码放在纯白底板上，并留出白边，浅色、深色模式都能扫。
- **电脑端记住窗口大小**：把窗口拖成合适的大小后，下次打开还是这个大小（最大化时关闭，下次打开是还原后的大小）；第一次打开默认放宽到约 750×760。
- **新增公网远程传输配置说明**：「设置 → 使用帮助 → 公网远程传输怎么配置」，分步骤说明需要准备什么、每台设备要填的三项、怎么用校验码确认口令一致，并可一键打开完整的 VPS 部署指南。

传输功能、聊天记录和已配对设备都不变。

## 下载

已安装 v1.8.0 或 v1.8.1 的，在「设置 → 软件更新」点「检查更新」即可一键升级。

- Android：`mengren-kuaichuan-android-v1.8.2.apk`，直接覆盖安装（签名与之前版本相同）。
- Windows：`mengren-kuaichuan-windows-x64-v1.8.2.zip`，解压后双击「创建桌面快捷方式.cmd」，再从桌面图标打开。

校验值见 `SHA256SUMS-v1.8.2.txt`。程序没有数字签名，Windows 或安全软件可能会提示，选择「仍要运行」即可。

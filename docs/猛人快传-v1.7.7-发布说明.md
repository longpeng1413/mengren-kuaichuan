# 猛人快传 v1.7.7 修复候选版（rc.1）

源码/应用版本 `1.7.7+24`，GitHub 标签 `v1.7.7-rc.1`。这是候选版，不覆盖 v1.7.6 正式发布，待长时间后台与休眠/网络恢复实机回归后再转正式。

## 修复内容

- 修复 Windows 长时间后台时 UDP 读循环空转拖住窗口、托盘的问题。关闭读通知后分批接收，通过事件循环 Timer 恢复；连续空读退避并延迟重建，防止网络异常耗尽界面执行机会。
- UDP 绑定单飞、旧回调与新 socket 隔离，关闭前先禁用读写通知；不清理用户聊天、文件或配置。
- Windows 隐藏到托盘后仍持续监听广播和发送两秒周期公告，保留 v1.7.6 的已知设备单播保活；后台后来加入的新设备仍自动识别。没有启动第二个进程抢占 UDP 端口，没有套用 Android 的后台暂停策略。
- 协议、VPS、令牌、家庭加密口令及 200 MiB 公网单文件上限不变。

## 验证与边界

- 应用静态检查无问题，48 项测试通过；含 11 项 UDP 防空转/生命周期/真实回环/后台新设备回归。公网协议 5 项、中转服务 7 项测试和静态检查通过。
- Android / Windows Release 构建成功；APK 签名和 Manifest、Windows 单实例、UDP/TCP 监听、ZIP 完整读取和本机异常 UDP 压力检查通过。
- Android versionCode 24，升级证书与 v1.7.6 相同，可覆盖安装。主要修复 Windows，手机原 v1.7.6 与候选 Windows 协议兼容，不强制升级手机。
- 仍待实测：整夜后台、休眠/唤醒、切换网络、托盘右键退出，以及 Android 共享代码回归。短时检查不能保证所有长时间运行场景。

## 安装

Windows 完整解压 ZIP 到固定目录，先退出旧软件，再运行 `lan_transfer.exe`。首次使用或目录改变后运行一次 `enable_lan_access.cmd`，因为规则绑定程序路径。不要只复制 EXE。

详见仓库的 `docs/猛人快传-v1.7.7-安装与测试说明.md` 与 `docs/开发交接说明-v1.7.7.md`。请使用 `SHA256SUMS-v1.7.7-rc.1.txt` 校验下载文件。

# 猛人快传 v1.8.2 安装与测试说明

v1.8.2 是 v1.8.1 的小修复版：二维码改为永远白底黑码，设置的「使用帮助」新增公网远程传输的配置步骤。传输功能、协议、设置、聊天记录和已配对设备都不变。

## 安装

- **已经装了 v1.8.0 或 v1.8.1**：打开「设置 → 软件更新 → 检查更新」，点「立即更新」即可。
- **第一次安装（Windows）**：把压缩包完整解压到一个固定文件夹（不要放在 `C:\Program Files`），双击「创建桌面快捷方式.cmd」，再从桌面图标打开；手机发现不了电脑时，双击 `enable_lan_access.cmd` 并在弹窗里点「是」。
- **Android**：直接覆盖安装 APK（签名与之前相同），已装 v1.8.0 以上的也可以一键更新。

## 这一版的变化

- **二维码永远白底黑码**：深色模式下，以前二维码背后是深色卡片，手机扫不出来；现在二维码放在纯白圆角底板上，四周留白边，浅色、深色模式都一样。
- **公网远程传输配置说明**：「设置 → 使用帮助 → 公网远程传输怎么配置」，分 4 步讲清楚需要什么、每台设备填哪三项、怎么用校验码确认口令一致、配好后界面上怎么显示；底部有「查看完整部署指南」按钮，打开 GitHub 上的 VPS 部署步骤。「公网远程传输」一栏未启用时也会提示去看这条帮助。

## 测试

1. 在深色模式下打开右上角二维码按钮，用手机扫码，应能直接识别。
2. 打开「设置 → 使用帮助 → 公网远程传输怎么配置」，确认步骤能展开，「查看完整部署指南」能在浏览器里打开。
3. 从 v1.8.1 一键更新到 v1.8.2，聊天记录和设置应保留。

# 猛人快传 v1.7.1 安装与测试说明

## 安装

### Android

1. 打开 `猛人快传-android-v1.7.1.apk`。
2. 选择更新或覆盖安装，不要先卸载旧版，以保留设置和聊天记录。
3. 打开后确认标题显示“猛人快传 v1.7.1”。

### Windows

1. 在系统托盘右键旧版猛人快传，选择“彻底退出”。
2. 完整解压 `猛人快传-windows-x64-v1.7.1.zip` 到固定文件夹；不要只复制 `lan_transfer.exe`。
3. 新目录首次使用时，以管理员身份运行一次 `enable_lan_access.cmd`。
4. 启动 `lan_transfer.exe`，确认标题和文件版本均为 `1.7.1+14`。

## 公网配置

v1.7.1 沿用 v1.7.0 的中转地址、VPS 访问令牌和家庭加密口令，不需要修改服务器。所有参与公网传输的设备都应升级到 v1.7.1，并保持三项配置完全一致。

## 建议测试

1. 不同网络下确认对方显示为“公网 VPS 中转”。
2. 双向发送文字和小图片，确认基础连接正常。
3. 手机向 Windows 发送 100–200 MiB PDF/视频，确认手机立即显示发送进度、百分比和速度。
4. 分别在发送端和接收端点击停止，确认另一端结束且没有残留 `.part` 文件。
5. 传输中强制结束发送端，确认接收端在断线或最多 45 秒后自动清理进度。
6. 长传输时反复点击输入框、滚动、返回和重新进入会话，确认 Android 保持响应。
7. 再测试同一局域网和 5 GHz 热点，确认本地路线仍优先且速度不受公网修复影响。

如果 Android 仍出现无响应，请记录发生时间和此前操作，重启后从“设置 → 诊断日志”导出日志。日志不会保存聊天正文、家庭口令或文件内容。

# 猛人快传 v1.7.8 安装与测试说明

v1.7.8 只更换了图标（红宝石配色），功能与 v1.7.7-rc.2 相同，设置、聊天记录和已配对设备都会保留。

## Windows

1. 在右下角托盘的猛人快传图标上右键「彻底退出」旧版。
2. 解压 `猛人快传-windows-x64-v1.7.8.zip` 到新文件夹，双击 `猛人快传.exe`。桌面快捷方式请改为指向新的 `猛人快传.exe`。
3. 防火墙规则绑定的是程序路径。换了文件夹后，如果手机发现不了电脑，右键 `enable_lan_access.cmd` →「以管理员身份运行」，重新允许局域网访问。
4. 检查：窗口标题 v1.7.8；任务栏、托盘为红色「猛」字图标。

## Android

直接覆盖安装 APK（签名与之前相同），桌面图标变为红色「猛」字。如果桌面还显示旧图标，重启桌面或手机即可。

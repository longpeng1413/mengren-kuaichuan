# 猛人快传 v1.7.2 安装与测试说明

## 安装

### Android

1. 打开 `猛人快传-android-v1.7.2.apk`。
2. 选择覆盖安装，不要卸载旧版，以保留设置和聊天记录。
3. 打开后确认标题显示“猛人快传 v1.7.2”。

### Windows

1. 在托盘右键旧版猛人快传并选择“彻底退出”。
2. 完整解压 `猛人快传-windows-x64-v1.7.2.zip`；不能只复制 EXE。
3. 新目录首次使用时，以管理员身份运行一次 `enable_lan_access.cmd`。
4. 启动 `lan_transfer.exe`，确认文件版本为 `1.7.2+15`。

## 公网测试

猛人快传不提供公共中转服务器。公网功能必须先按照
[自建 VPS 中转指南](自建VPS中转指南-v1.7.2.md) 部署你自己的服务器，
再在所有个人设备中填写你自己的：

- `wss://你的域名/v1/relay`
- VPS 访问令牌（不是 SSH 密码）
- 家庭加密口令

不要使用软件作者或其他人的中转地址。安装包中不包含可直接使用的中转配置。

1. 手机和 Windows 都升级到 v1.7.2，填写相同的自建配置，并确认显示“公网 VPS 中转”。
2. 双向发送文字和小图片，确认不再出现 `unknown_receipt`。
3. 双向发送 60–200 MiB PDF 或视频，记录稳定速度而不是刚开始几秒的瞬时值。
4. 分别在发送端和接收端停止，确认另一端结束且没有 `.part` 文件。
5. 长传输时持续操作 Android 输入框、滚动和返回，确认界面保持响应。

公网协议仍为 3。已有自建服务的用户不需要重新填写自己的地址、访问令牌和家庭加密口令；VPS 容器应更新到 v1.7.2 服务端以启用 120 秒迟到回执容错。

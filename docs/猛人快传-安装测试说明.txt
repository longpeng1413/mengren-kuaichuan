猛人快传 Windows 安装与测试说明

1. 将“猛人快传-windows-x64-v1.6.1.zip”完整解压到一个固定文件夹。
2. 不要只复制 lan_transfer.exe；data 文件夹和所有 DLL 必须与它放在一起。
3. 首次使用先双击 enable_lan_access.cmd，并在 Windows 用户账户控制中点击“是”。
   该脚本只为当前程序开放私有局域网地址的 UDP 53317 和 TCP 53318，
   同时支持 192.168.0.x 与 192.168.110.x 这类二级路由网络。
4. 双击 lan_transfer.exe 启动。窗口标题应显示“猛人快传 v1.6.1”。
   如果软件已经在右下角托盘运行，再点桌面快捷方式只会恢复原窗口，不会重复启动或占用 53318 端口。
5. 点击右上角二维码按钮，可显示本机 IP、8 位配对码和二维码。
6. 安卓手机安装新版“猛人快传”，打开二维码页面，扫描电脑二维码。
7. 扫码失败时，可在手机中选择“手动输入 IP 和配对码”。
8. 配对成功后，设备会出现在列表中并标注“二维码连接”；点击设备进入聊天窗口。
9. 聊天窗口可发送文字、可点击链接、图片、视频和任意文件；文件发送时显示百分比、
   进度条、传输速度和已发送/总大小；接收端也显示相同进度。接收设备需要在弹窗中点击“接收”。
10. 请先双向发送一条文字和一个小图片，再测试大文件。
11. Windows 对话框中按 Enter 发送文字，Shift+Enter 换行；也可直接把一个或多个文件拖入聊天区。
12. 收到文件后可直接点击文件气泡，安卓会调用系统中可用的应用打开；气泡和接收提示中会显示实际保存路径。
13. Windows 点击右上角“×”只会隐藏到系统托盘；单击右下角“猛”字托盘图标恢复窗口，
    右键托盘图标选择“彻底退出”才会结束程序。
14. 右上角“设置”可选择浅色、深色或跟随系统模式，也可切换强调色、设置 Windows 开机自启动，
    以及更改默认保存位置。
15. 安卓默认把接收文件写入“系统下载/猛人快传”，也可在设置中选择其他文件夹；
    写入成功后自动删除应用内临时副本。
16. 在安卓相册或文件管理器中长按文件并选择“分享”，可选择“猛人快传”；进入软件后点击目标设备发送。
    微信表格等文件的“其他应用打开”列表中也可选择“猛人快传”，效果与分享入口相同。
17. 会话右上角菜单可以清空消息与缓存或移除设备。清空缓存不会删除已经保存到系统下载或自定义目录的文件。
18. 安卓设置页可导出或清除诊断日志。导出文件位于“系统下载/猛人快传”；每份日志最多约 1 MB，
    只保留当前和上一份，并自动删除 7 天前的日志。日志不保存聊天文字或传输文件内容。
19. 等待对方确认和正在发送文件时，发送进度栏右侧均有停止按钮。取消后接收端会关闭确认框，
    或删除尚未完成的 .part 临时文件；配对通道随后会自动恢复连接。

二维码连接由手机主动连接电脑，可用于手机位于二级路由器、电脑位于上级网络的情况。
同一设备同时存在自动发现和二维码连接时，软件会优先使用可双向通信的二维码连接。
本版本仍不使用公网服务器或云存储。

v1.5.0 起优化了大文件传输：降低进度界面刷新频率、使用更大的网络块和磁盘回压窗口，
并关闭视频/压缩包无效的二次压缩。实际速度仍取决于手机 Wi-Fi 频段、信号、路由器、有线端口和手机存储写入速度。
聊天图片只按缩略图尺寸解码，图片缓存限制为 32 MB；这可降低浏览图片会话后的内存增长，
但 Flutter Windows 引擎的基础占用仍会高于部分原生桌面软件。

v1.6.0 修复手机与电脑同时恢复扫码连接时可能互相关闭通道的问题，并在发送前重新选择实时可用的
配对或局域网直连路线。配对协议已升级，请确保参与配对的 Android 和 Windows 设备全部使用 v1.6.0。

v1.6.1 新增手机热点互传：手机 A 打开便携热点，手机 B 连接该热点，然后在任意一台手机中打开
“二维码 / 手动连接”，由另一台手机扫描二维码。软件会自动枚举热点网卡，并向热点网段发送定向广播；
如果系统限制自动发现，二维码或手动 IP 仍可建立双向连接。测试时两台手机都应安装 v1.6.1，依次验证
A 到 B、B 到 A 的文字、小图片和大文件；全程不需要公司/家庭路由器，也不经过互联网。

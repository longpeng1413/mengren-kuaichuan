猛人快传 Windows 使用说明

一、第一次使用
1. 把压缩包完整解压到一个固定的文件夹（例如 D:\猛人快传），不要只复制 猛人快传.exe，
   data 文件夹和所有 DLL 必须和它放在一起。不要放在 C:\Program Files 里，否则无法一键更新。
2. 双击“创建桌面快捷方式.cmd”，桌面上就会出现“猛人快传”图标。以后从桌面图标打开即可。
3. 双击 enable_lan_access.cmd，在 Windows 弹出的“是否允许更改”里点“是”。
   它只为本程序放行局域网的 UDP 53317 和 TCP 53318，手机才能找到电脑。
4. 打开猛人快传。手机和电脑连同一个 Wi-Fi 或热点，双方会自动出现在“附近设备”里；
   找不到时，点右上角二维码按钮，用手机扫码或手动输入 IP 和配对码。

二、日常使用
- 点击设备进入对话，可发送文字、链接、图片、视频和任意文件；文件也可以直接拖进对话窗口。
- 点聊天里的图片在单独的「图片查看」窗口打开，可缩放、旋转、复制、另存为；点「编辑」（或在图片上右键选「编辑」）可以画框、箭头、写字、打马赛克、裁剪，编辑后直接发送或复制，原图不变。
  Enter 发送，Shift+Enter 换行。发送和接收文件时都可以随时停止。
- 截图或在资源管理器里复制文件后，在输入框按 Ctrl+V，确认后即可发送。
- 右键任意消息：复制、转发给其他设备、引用回复、删除；点引用内容可以跳回原消息。
- 语音：按住输入框旁的麦克风说话，松开发送（上滑取消，最长 60 秒）；点一下麦克风是语音输入，
  说完再点一次，文字会填进输入框。右键语音消息选“转文字”。第一次转文字要下载约 229 MB 的
  离线识别模型（国内网络可能需要代理）。提示无法使用麦克风时，到“Windows 设置 → 隐私和安全性
  → 麦克风”打开“允许桌面应用访问麦克风”。
- 对方不在线时发的内容会先排队，对方打开猛人快传后自动送达（本机要保持运行）。
- 点右上角“×”只会隐藏到右下角托盘；单击托盘图标恢复窗口，右键托盘图标选“彻底退出”才会关闭。
- 设置里可以切换浅色/深色、强调色、开机自启动（默认静默启动，只在托盘运行）、文件保存位置、
  自动接收文件，查看并清空各种缓存，配置自己的 VPS 远程传输，以及导出诊断日志（出问题时发给开发者）。

三、更新
- 软件每天会自动检查一次新版本，也可以在“设置 → 软件更新 → 检查更新”手动检查。
- 发现新版本后点“立即更新”：下载、核对校验值后自动关闭、替换文件、几秒后重新打开。
  程序文件夹不变，桌面快捷方式、防火墙放行和开机自启都不用重新设置。

四、说明
- 同一局域网内直接传输，不经过公网；只有启用了自己的 VPS 时，跨网络的设备才走加密中转，
  界面上会明确显示实际路线。公网单个文件上限 200 MiB。
- 语音转文字完全在本机离线完成，录音不会上传。
- 发送时提示“连接被中途断开”：多半是 AdGuard、杀毒软件或防火墙接管了猛人快传的网络连接，
  请在那个软件里把猛人快传设为不过滤（AdGuard：设置 → 网络 → 应用程序管理）。
- 程序没有数字签名，Windows 或安全软件可能提示“未知发布者”，选择“仍要运行”即可。
- 大文件建议使用 5 GHz Wi-Fi 或热点，并关闭热点的“兼容模式”，速度会快很多。
- 详细说明见同文件夹里的“猛人快传-v版本号-安装与测试说明.md”。

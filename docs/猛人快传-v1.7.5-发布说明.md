# 猛人快传 v1.7.5 发布说明

v1.7.5 修复 Android 应用在后台停留后恢复前台可能无响应的问题。公网协议仍为 3，VPS 不需要重新部署，原有公网地址、访问令牌和家庭加密口令无需修改。

## 主要变化

- Android 在后台时暂停局域网发现和自动重连，回到前台后再有序恢复，避免系统限制网络时持续占用界面线程。
- 广播暂时不可用时不再反复销毁、重建 UDP socket；真正的 socket 故障仍会受控重试。
- Android 网卡诊断日志只在网络接口变化时写入，减少稳定网络下的无效磁盘写入。

## 升级提示

- Android 请直接覆盖安装，不要卸载。可从 v1.7.4 或 v1.7.5 测试版升级，原身份、设置、聊天记录和公网配置会保留。
- Windows 端未针对本问题做功能修改；旧版运行正常时无需更新，但新 Windows 包可作为版本统一安装。
- 局域网配对协议仍为 2，公网协议仍为 3，因此 v1.7.4 Windows 可继续与 v1.7.5 Android 互传。

# 猛人快传 v1.7.8

**新图标「红宝石」**：「猛」字、龙纹、边框和背景整体换成红色系。Windows 程序、任务栏、托盘图标和 Android 桌面图标全部更换。原来的金色图标和同一作者的猛人截图教鞭一模一样，放在一起分不清；现在三款软件分别是金色（截图教鞭）、红色（快传）、紫色（猛人学习），任务栏上一眼就能认出来。

功能与 v1.7.7-rc.2 相同：链接可以拖选、长按复制；Windows 启动程序叫 `猛人快传.exe`；修复 Windows 长时间后台后窗口和托盘无响应。局域网和公网协议、VPS 中转、聊天记录、已配对设备都不变。

## 下载

- Android：`mengren-transfer-android-v1.7.8.apk`，直接覆盖安装（签名与之前版本相同）。
- Windows：`mengren-transfer-windows-x64-v1.7.8.zip`，解压后双击 `猛人快传.exe`。

## 从旧版升级（Windows）

1. 在右下角托盘的猛人快传图标上右键「彻底退出」。
2. 把新版解压到新文件夹，桌面快捷方式改为指向新的 `猛人快传.exe`。
3. 防火墙规则绑定的是程序路径。如果手机发现不了电脑，右键 `enable_lan_access.cmd` →「以管理员身份运行」。

校验值见 `docs/SHA256SUMS-v1.7.8.txt`。程序没有数字签名，Windows 或安全软件可能会提示，选择「仍要运行」即可。

# 猛人快传 v1.8.3

小改动版。

- **设置页底部**：图标下面改为显示作者 longpeng1413 和项目主页链接（github.com/longpeng1413/mengren-kuaichuan），点一下在浏览器打开。
- **首页**：「默认纯局域网传输，不经过公网服务器」这句说明移到首页本机卡片下方，带一个小锁图标；启用公网中转后显示为「局域网优先；仅远程设备使用加密 VPS 中转」。

传输功能、聊天记录、已配对设备和窗口大小记忆都不变。

## 下载

已安装 v1.8.0 及以上的，在「设置 → 软件更新」点「检查更新」即可一键升级。

- Android：`mengren-kuaichuan-android-v1.8.3.apk`，直接覆盖安装（签名与之前版本相同）。
- Windows：`mengren-kuaichuan-windows-x64-v1.8.3.zip`，解压后双击「创建桌面快捷方式.cmd」，再从桌面图标打开。

校验值见 `SHA256SUMS-v1.8.3.txt`。程序没有数字签名，Windows 或安全软件可能会提示，选择「仍要运行」即可。

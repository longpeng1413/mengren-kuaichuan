# 猛人快传 v1.11.1

- **修复电脑端无法录语音**：v1.11.0 在 Windows 上按住麦克风或点语音输入时提示“无法开始录音：……指定的对象或值不存在”。原因是录音中的临时文件名不以 `.wav` 结尾，Windows 的录音组件按扩展名决定文件格式，认不出就报错。现在临时文件改为 `.wav` 结尾，已在电脑上用真实麦克风验证可以正常录音。
- 录音等操作出错时，提示里只显示可读的错误说明，不再夹带程序内部的错误代码。

## 下载

已安装 v1.8.0 及以上的，在「设置 → 软件更新」点「检查更新」即可一键升级。

- Android：`mengren-kuaichuan-android-v1.11.1.apk`，直接覆盖安装（签名与之前版本相同）。
- Windows：`mengren-kuaichuan-windows-x64-v1.11.1.zip`。

校验值见 `SHA256SUMS-v1.11.1.txt`。程序没有数字签名，Windows 或安全软件可能会提示，选择「仍要运行」即可。

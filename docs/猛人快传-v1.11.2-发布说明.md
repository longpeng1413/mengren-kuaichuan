# 猛人快传 v1.11.2

- **语音消息声音变大**：电脑（尤其是摄像头自带麦克风、笔记本麦克风）录的语音以前音量只有正常说话的几分之一，播放时听不清。现在录完会像微信一样自动调整音量：整体调到正常说话的水平，最响的地方不超过上限（不会破音），最多放大约 16 倍（安静时的底噪不会被放大成噪音）。实测几条小声录音的平均音量从 -33～-46 dBFS 提升到 -20～-23 dBFS，原本音量正常的录音保持不变。
- 收到旧版本发来的小声语音，也会在保存时自动调大。
- 语音输入（听写）前也会先调整音量，小声说话时识别更准。
- 本版手机和电脑都更新（v1.11.1 只更新了电脑端）。

## 下载

已安装 v1.8.0 及以上的，在「设置 → 软件更新」点「检查更新」即可一键升级。

- Android：`mengren-kuaichuan-android-v1.11.2.apk`，直接覆盖安装（签名与之前版本相同）。
- Windows：`mengren-kuaichuan-windows-x64-v1.11.2.zip`。

校验值见 `SHA256SUMS-v1.11.2.txt`。程序没有数字签名，Windows 或安全软件可能会提示，选择「仍要运行」即可。

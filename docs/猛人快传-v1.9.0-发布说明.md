# 猛人快传 v1.9.0

**不用再点“接收”了，手机也能在后台接收。**

- **自动接收文件**（设置 → 接收）：局域网收文件不再每次都弹“接收文件？”。可以选：
  - 只限连接过的设备（默认）：你给它发过东西、和它配对过、或手动接收过它文件的设备，发来的文件直接保存；陌生设备第一次发文件仍会询问。
  - 局域网内所有设备：局域网里谁发来的都直接保存。
  - 每次都询问：和以前一样。
  文字消息、公网 VPS 中转收到的文件（单个不超过 200 MiB）一直都是直接接收。电脑隐藏到托盘时也不会再因为没看到确认框而漏收文件。
- **后台持续接收**（手机，设置 → 接收，默认关闭）：打开后，猛人快传切到后台、手机熄屏也能继续被电脑发现、接收文件和消息，收到时弹通知。通知栏会常驻一条“猛人快传正在后台接收”，耗电会多一些。打开时会请求“通知”权限，并引导你允许猛人快传后台运行。
- 设置「使用帮助」新增“自动接收和后台接收”说明；下载更新失败时会提示检查代理软件的“分应用代理”。

## 下载

已安装 v1.8.0 及以上的，在「设置 → 软件更新」点「检查更新」即可一键升级。

- Android：`mengren-kuaichuan-android-v1.9.0.apk`，直接覆盖安装（签名与之前版本相同）。
- Windows：`mengren-kuaichuan-windows-x64-v1.9.0.zip`。

校验值见 `SHA256SUMS-v1.9.0.txt`。程序没有数字签名，Windows 或安全软件可能会提示，选择「仍要运行」即可。

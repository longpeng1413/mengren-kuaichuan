# 猛人快传 v1.9.1 安装与测试说明

v1.9.1 新增离线排队发送，修复电脑端回车发送后输入框失去焦点，并为华为等手机加上“系统后台设置”入口。协议不变，设置、聊天记录和已配对设备都保留。

## 安装

- **已是 v1.8.0 以上**：「设置 → 软件更新 → 检查更新」一键升级。
- **Android**：也可以直接覆盖安装 APK。

## 测试

### 离线排队

1. 手机退到后台（不开“后台持续接收”）或关掉猛人快传，等电脑上这台手机变成灰色“离线”。
2. 在电脑上点开它，发一条文字和一个小文件：气泡下应显示“等待对方上线，上线后自动发送”，首页这台手机显示“2 条待发送”。
3. 打开手机上的猛人快传：几秒内两条内容应自动发到手机，电脑上的“等待”提示消失。
4. 再排一条，点“取消”：应从对话里删除，手机上线后也不会收到。
5. 手机给电脑发也测一次（电脑彻底退出后再打开）。

### 电脑端连续输入

在电脑的对话里输入文字按 Enter 发送，不点鼠标直接继续输入第二句、再按 Enter，应能连续发送。

### 华为手机后台接收

1. 设置 → 接收 → 打开“后台持续接收”，允许通知、允许后台运行。
2. 点出现的“系统后台设置”，在华为的“应用启动管理”里把猛人快传改成“手动管理”，打开允许自启动、允许关联启动、允许后台活动。
3. 在最近任务里把猛人快传卡片下拉锁定。
4. 回到桌面熄屏 5 分钟，从电脑发文字：手机应弹出通知。

出问题时导出诊断日志。相关记录：`outbox_queued`、`outbox_delivered`、`outbox_still_unreachable`、`background_receive_status`（含 `ignoring_battery`、`notifications` 和手机品牌）。

# 猛人快传 v1.8.3 安装与测试说明

v1.8.3 是小改动版：设置页底部显示作者和项目主页链接，「默认纯局域网传输」的说明移到首页。传输功能、协议、设置、聊天记录和已配对设备都不变。

## 安装

- **已经装了 v1.8.0 及以上**：打开「设置 → 软件更新 → 检查更新」，点「立即更新」即可。程序在原文件夹里原地替换，桌面快捷方式和防火墙放行都不用动。
- **第一次安装（Windows）**：把压缩包完整解压到一个固定文件夹（不要放在 `C:\Program Files`，文件夹名最好不带版本号，以后一直用它），双击「创建桌面快捷方式.cmd」，再从桌面图标打开；Windows 弹出防火墙提示时点「允许」。
- **Android**：直接覆盖安装 APK（签名与之前相同），已装 v1.8.0 以上的也可以一键更新。

## 测试

1. 首页本机卡片下方应有一行带小锁的「默认纯局域网传输，不经过公网服务器」。
2. 打开设置，拉到最底部：图标下面应显示「作者 longpeng1413」和 GitHub 链接，点链接能在浏览器打开项目主页。
3. 从 v1.8.2 一键更新到 v1.8.3，窗口大小、聊天记录和设置应保留，不应再弹防火墙提示。

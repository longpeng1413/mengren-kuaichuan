# 猛人快传 v1.11.2 安装与测试说明

v1.11.2 解决语音消息声音太小：录完自动把音量调到正常说话的水平，收到旧版本发来的小声语音也会自动调大。手机和电脑都更新。协议、设置和聊天记录不变。

## 安装

- 「设置 → 软件更新 → 检查更新」一键升级；Android 也可以直接覆盖安装 APK。

## 测试

1. 电脑和手机分别按住麦克风正常说话录一条语音，发给对方，播放音量应和平时手机通话、听歌的音量差不多，不再需要凑近听。
2. 让对方用旧版本发一条语音过来，新版收到后播放也应该变大。
3. 很近、很大声地录一条：不应出现破音（音量不会被调到超过上限）。
4. 什么都不说、安静地录一条：底噪会被放大一些，但不会变成很响的噪音（最多放大约 16 倍）。

升级前已经收到或发出的语音不会被改动，音量保持原样。出问题时导出诊断日志，收到语音的记录里会写放大了多少（`voice_received … gain_db=…`）。
